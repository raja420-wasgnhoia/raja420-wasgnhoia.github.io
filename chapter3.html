Formulas

r = xi + yj + zk
|r| = √(x² + y² + z²)
r = (mb + na)/(m + n)
r = (a + b)/2
r = (2b − 3a)/(2 − 3)
r̂ = r/|r|
λ = x₁/x₂ = y₁/y₂ = z₁/z₂
λr = λ(xi + yj + zk)
a · b = |a||b| cos θ
cos α = |OA|/|OP| = x/|r|
cos β = |OB|/|OP| = y/|r|
cos γ = |OC|/|OP| = z/|r|
l = cos α
m = cos β
n = cos γ
l² + m² + n² = 1
cos θ = (a · b)/(|a||b|)
θ = cos⁻¹[(a · b)/(|a||b|)]
θ = cos⁻¹[(a₁b₁ + a₂b₂ + a₃b₃) / (√(a₁² + a₂² + a₃²) √(b₁² + b₂² + b₃²))]
cos(α − β) = cos α cos β + sin α sin β
Area of triangle = ½|a × b|
Volume of Tetrahedron = ⅙[a · (b × c)]

📖 Definitions

• Unit Vector: Vector with magnitude 1 in the direction of r.

• Scalar Multiplication: λv = (λx)i + (λy)j + (λz)k

• Parallel Vectors: r₁ = λr₂ for non-zero scalar λ.

• Zero Vector: All components are zero.

• If θ is the angle between two non-zero vectors a and b.

📌 Key Points

• Position vector of P(x, y, z) is OP = xi + yj + zk.

• If λ is positive, same direction. If λ is negative, opposite direction.

• Every vector has an opposite vector; their sum is zero.

• 0 is identity for vector addition. Adding zero vector doesn't change vector.

• Same vectors = 1 (θ = 0°).

• Different vectors = 0 (θ = 90°).

• Sum of squares of direction cosines of any vector is always 1.

• sin(α − β) = sin α cos β − cos α sin β.
