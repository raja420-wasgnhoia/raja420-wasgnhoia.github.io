Important Formulas

1. Cartesian Product

A × B = {(x, y) | x ∈ A and y ∈ B}
If n(A) = p and n(B) = q, then n(A × B) = pq
Number of subsets of A × B = 2pq

2. Function Notation

f : A → B
y = f(x)

3. Function Operations

(f + g)(x) = f(x) + g(x)
(f − g)(x) = f(x) − g(x)
(f × g)(x) = f(x) × g(x)
(f ÷ g)(x) = f(x) ÷ g(x), where g(x) ≠ 0

4. Composition of Functions

(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))
f(f(x)) = f2(x)
f(f2(x)) = f3(x)

5. Inverse Function

f : X → Y    ⇒    f−1 : Y → X
y = f(x)    ⇒    x = f−1(y)
f(f−1(x)) = f−1(f(x)) = x
(f−1)−1 = f

6. Constant Function

y = f(x) = a = ax0

7. Linear Function

y = f(x) = ax + b,   a ≠ 0

8. Identity Function

y = f(x) = x

9. Absolute Value Function

|x| = { x, if x ≥ 0 ; −x, if x < 0 }
f(x) = |x|

10. Linear Graphs of y = nx

y = nx
Slope = n

11. Quadratic Function

f(x) = ax2 + bx + c,   a ≠ 0
y = a(x − h)2 + k
h = −b / 2a
k = c − b2 / 4a
Vertex = (h, k)
Axis of symmetry: x = h

12. Cubic Function

f(x) = ax3 + bx2 + cx + d,   a ≠ 0

13. Square Root Function

f(x) = √x,   x ≥ 0

14. Reciprocal Function

f(x) = k / x,   x ≠ 0, k ≠ 0
f(x) = 1 / x

15. Exponential Function

f(x) = ax,   a > 0, a ≠ 1

16. Power Function

y = xn
x0 = 1
x−1 = 1/x
x−2 = 1/x2

17. Gradient

Gradient = Change in y / Change in x
Gradient = (y2 − y1) / (x2 − x1)
Slope = Rise / Run

Definitions

Cartesian Product

The Cartesian product of two sets A and B is the set of all ordered pairs (x, y) where x belongs to A and y belongs to B.

Relation

A relation from A to B is any subset of the Cartesian product A × B.

Function

A function f: A → B maps each element of A to a unique element of B.

Domain

The domain of a function is the set of first elements of its ordered pairs.

Range

The range of a function is the set of second elements or images of its ordered pairs.

Codomain

In f: A → B, the set B is called the codomain of the function.

Image

The second element corresponding to a preimage is called its image.

Preimage

The first element corresponding to an image is called its preimage.

Into Function

A function is called into if at least one element of the codomain is not an image. Thus, Range(f) is a proper subset of B.

Onto Function

A function is called onto or surjective if every element of the codomain is the image of at least one element of the domain.

One-to-One Function

A function is one-to-one if distinct elements of the domain have distinct images.

Injective Function

A function that is both into and one-to-one is called an injective function.

Bijective Function

A function that is both onto and one-to-one is called a bijective function.

Function Evaluation

Function evaluation is the process of finding the dependent value by substituting a specific value of the independent variable.

Inverse Function

The inverse of a function reverses the effect of the original function. An inverse function exists when the function is bijective.

Constant Function

A polynomial function of degree zero is called a constant function.

Linear Function

A polynomial function of degree one is called a linear function.

Identity Function

A function in which every input has the same output is called an identity function.

Absolute Value Function

The function f(x) = |x| is called the absolute value or modulus function.

Quadratic Function

A polynomial function of degree two is called a quadratic function.

Cubic Function

A polynomial function of degree three is called a cubic function.

Square Root Function

The function f(x) = √x, where x ≥ 0, is called a square root function.

Reciprocal Function

A function of the form f(x) = k/x, where x ≠ 0 and k ≠ 0, is called a reciprocal function.

Exponential Function

A function of the form f(x) = aˣ, where a > 0 and a ≠ 1, is called an exponential function.

Gradient of a Curve

The gradient of a curve at a given point is the slope of the tangent line drawn to the curve at that point.

Tangent

A tangent to a curve is a line that touches the curve at a given point externally. The slope of the tangent gives the gradient of the curve at that point.

Graph Facts

  • A vertical line intersects the graph of a function at most once. This is called the vertical line test.
  • The graph of y = 0 is the x-axis.
  • The graph of a constant function is a horizontal straight line.
  • The graph of a linear function is a straight line.
  • The graph of y = x passes through the origin and bisects the first and third quadrants.
  • The graph of y = |x| is V-shaped with vertex at the origin.
  • The domain of y = |x| is all real numbers and its range is all non-negative real numbers.
  • Graphs of y = nx pass through the origin.
  • For n > 0, y = nx lies through the first and third quadrants.
  • For n < 0, y = nx lies through the second and fourth quadrants.
  • The graph of a quadratic function is a parabola.
  • If a > 0 in y = ax² + bx + c, the parabola opens upward and its vertex gives the minimum value.
  • If a < 0, the parabola opens downward and its vertex gives the maximum value.
  • The axis of symmetry of a quadratic graph is x = h.
  • The graph of y = x³ is symmetric about the origin and passes through the origin.
  • The domain and range of a cubic function are all real numbers.
  • The graph of y = √x lies in the first quadrant and increases as x increases.
  • The domain and range of y = √x are the non-negative real numbers.
  • The reciprocal graph y = 1/x has two branches in the first and third quadrants.
  • The graph y = 1/x is undefined at x = 0.
  • The graph y = 1/x never touches the x-axis or y-axis.
  • The domain and range of y = 1/x are all real numbers except zero.
  • The exponential graph y = 2ˣ has y-intercept 1 and horizontal asymptote y = 0.
  • The graphs of y = xⁿ for positive and negative integer n pass through (1, 1) when defined for x > 0.
  • The intersection points of a linear and quadratic graph give the graphical solutions of the simultaneous equations.
  • A positive gradient means the tangent rises from left to right.
  • A negative gradient means the tangent falls from left to right.
  • The slope of a vertical line is undefined.

Most Important Things

  • Every function is a relation, but every relation is not necessarily a function.
  • For a relation to be a function from A to B, its domain must be A and no first element can be repeated.
  • In an onto function, Range = Codomain.
  • In an into function, Range is a proper subset of the Codomain.
  • A one-to-one function has no repeated second elements.
  • An injective function is into and one-to-one.
  • A bijective function is onto and one-to-one.
  • An inverse function exists for a bijective function.
  • Domain of f = Range of f⁻¹.
  • Range of f = Domain of f⁻¹.
  • For addition and subtraction of functions, perform the operation on their corresponding function values.
  • For division of functions, the denominator function must not be zero.
  • In composition, the output of the inner function becomes the input of the outer function.
  • For a quadratic function, the sign of a determines whether the parabola opens upward or downward.
  • The vertex of a parabola is its turning point.
  • The x-intercept is found by putting y = 0.
  • The y-intercept is found by putting x = 0.
  • The absolute value of a number represents its distance from zero.
  • The reciprocal of zero is undefined.
  • For reciprocal functions, the denominator cannot be zero.
  • The gradient of a curve is determined using the tangent at the required point.
  • Gradient = rise/run = change in y/change in x.
  • Real-life functions and graphs can represent distance, time, population, finance, temperature, supply, demand and many other quantities.
