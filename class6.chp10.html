FORMULAS & RULES

1. Mean

Mean = Sum of all values ÷ Number of values
Mean = Σx ÷ n
Σx = sum of the values, n = number of values.
Example: 129, 125, 123, 129, 124, 129, 123
Sum = 882, number of values = 7
Mean = 882 ÷ 7 = 126 cm

2. Median

First arrange the data in ascending order.
If n is odd:
Median position = (n + 1) ÷ 2
If n is even:
Median = (Middle value 1 + Middle value 2) ÷ 2
Example: 123, 123, 124, 125, 129, 129, 129
n = 7
Median position = (7 + 1) ÷ 2 = 4th value
Median = 125 cm

3. Mode

Mode = The value that occurs most frequently
Example: 2, 3, 5, 5, 8, 8, 8, 15, 10
8 occurs three times, more than any other value.
Mode = 8

4. Percentage

Percentage = (Original value ÷ Total value) × 100%
Refrigerator items = 20
Fruits: (8 ÷ 20) × 100 = 40%
Meat: (3 ÷ 20) × 100 = 15%
Chicken: (4 ÷ 20) × 100 = 20%
Eggs: (5 ÷ 20) × 100 = 25%

5. Pie Graph / Sector Diagram

Angle of sector = (Component value ÷ Total value) × 360°
Total angle of a complete pie graph = 360°
Percentage represented by a sector = (Sector angle ÷ 360°) × 100%
Family expenditure values: 50, 30, 20, 15, 35
Total = 50 + 30 + 20 + 15 + 35 = 150
A: (50 ÷ 150) × 360° = 120°
B: (30 ÷ 150) × 360° = 72°
C: (20 ÷ 150) × 360° = 48°
D: (15 ÷ 150) × 360° = 36°
E: (35 ÷ 150) × 360° = 84°

6. Probability

Theoretical probability = Number of favourable outcomes ÷ Total number of equally likely outcomes
P(E) = n(E) ÷ n(S)
n(E) = number of favourable outcomes
n(S) = total number of equally likely outcomes
Probability of an impossible event = 0
Probability of a certain event = 1
For any event E: 0 ≤ P(E) ≤ 1
Experimental probability = Number of times an event occurs ÷ Total number of trials
Example: A fair coin is tossed once.
P(Head) = 1 ÷ 2 = 1/2
P(Tail) = 1 ÷ 2 = 1/2
Example: A fair die is rolled once.
P(rolling a 4) = 1 ÷ 6 = 1/6
P(rolling an even number) = 3 ÷ 6 = 1/2

7. Multiple Bar Graphs

A multiple bar graph uses two or more bars for each category to compare related data sets.
Vertical multiple bar graph: Categories are shown on the horizontal axis, and values on the vertical axis.
Horizontal multiple bar graph: Categories are shown on the vertical axis, and values on the horizontal axis.

CONCEPTS

1. Data and Collection
Data is information collected through surveys, questions, measurements or observations. A survey is a way of collecting information by asking questions or observing events.
2. Raw, Organized, Ungrouped and Grouped Data
Raw data is collected in its original form. Organized data is arranged in a systematic order, such as ascending order. Ungrouped data lists individual observations, while grouped data organizes observations into groups or categories.
3. Discrete Data
Discrete data consists of countable values, usually whole numbers. Examples include the number of students in a class or the number of books on a shelf.
4. Continuous Data
Continuous data can take any value within a range, including decimals and fractions. Examples include height, age measured precisely, and temperature.
5. Mean
The mean is calculated by adding all values and dividing the sum by the number of values. It is affected by unusually large or small values.
6. Median
The median is the middle value after arranging the data in order. For an even number of observations, take the average of the two middle values.
7. Mode
The mode is the value that occurs most frequently. A data set may have one mode, more than one mode, or no mode if no value occurs more often than the others.
8. Multiple Bar Graph
A multiple bar graph compares two or more related data sets across the same categories. A key or legend identifies which bars represent each data set.
9. Pie Graph
A pie graph is a circular diagram divided into sectors. Each sector represents a part of the total, and the complete circle represents 100% or 360°.
10. Theoretical Probability
Theoretical probability is calculated from all possible equally likely outcomes. It does not require conducting an experiment.
11. Experimental Probability
Experimental probability is based on the results observed during actual trials or experiments. It may differ from theoretical probability, especially when the number of trials is small.

DEFINITIONS

Data: Information collected through surveys, measurements, questions or observations.
Survey: A method of collecting information by asking questions or observing events.
Raw Data: Data recorded in its original, unprocessed form.
Organized Data: Data arranged systematically, for example in ascending or descending order.
Ungrouped Data: Data in which individual observations are listed separately.
Grouped Data: Data organized into groups, classes or categories.
Discrete Data: Countable data that usually consists of separate whole-number values.
Continuous Data: Data that can take any value within a range, including fractions and decimals.
Mean: The sum of all observations divided by the total number of observations.
Median: The middle observation in an ordered data set, or the average of the two middle observations when the number of values is even.
Mode: The value that occurs most frequently in a data set.
Multiple Bar Graph: A graph that uses multiple bars in each category to compare related data sets.
Pie Graph: A circular graph divided into sectors that represent portions of a whole.
Probability: A measure of how likely an event is to occur.
Theoretical Probability: The ratio of favourable equally likely outcomes to the total number of equally likely outcomes.
Experimental Probability: The ratio of the number of times an event occurs to the total number of trials.
Outcome: A possible result of an experiment.
Favourable Outcome: An outcome that satisfies the event being considered.
Sample Space: The set of all possible outcomes of an experiment.

KEY POINTS

1. Always arrange data in ascending order before finding the median.
2. For an odd number of values, the median position is (n + 1) ÷ 2.
3. For an even number of values, add the two middle values and divide by 2.
4. The mean uses every value in the data set, while the median depends on the middle value or values.
5. A data set can have more than one mode or no mode.
6. Discrete data is countable; continuous data is measured.
7. In a vertical bar graph, categories are on the horizontal axis. In a horizontal bar graph, categories are on the vertical axis.
8. Use a key or legend to distinguish data sets in a multiple bar graph.
9. The sum of all sector angles in a pie graph is always 360°.
10. The sum of all percentages in a complete pie graph is 100%.
11. Theoretical probability is based on possible outcomes; experimental probability is based on observed results.
12. Probability is always between 0 and 1, inclusive.
13. An impossible event has probability 0; a certain event has probability 1.
14. In a fair coin toss, the probability of heads is 1/2. In a fair die roll, the probability of rolling any particular number is 1/6.
15. Check that all pie-chart sector angles add up to 360°. A calculator can help, but it cannot rescue incorrect arithmetic.
