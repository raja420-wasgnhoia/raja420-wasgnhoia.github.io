1. FORMULAS

Linear Equations

General linear equation in one variable: ax + b = 0, where a ≠ 0
For ax + b = c: x = (c − b)/a, where a ≠ 0
If the same quantity is added to or subtracted from both sides of an equation, equality is preserved.
Multiplying or dividing both sides of an equation by the same non-zero number preserves equality.

Equations with Rational Coefficients

A rational number can be written as p/q, where p and q are integers and q ≠ 0.
To clear fractional coefficients, multiply every term on both sides by the least common denominator (LCD).
For a rational equation, exclude any value that makes an original denominator equal to zero.

Radical Equations

If √A = B, then A = B², provided B ≥ 0.
If √A = √B, then A = B, where both sides are defined and non-negative.
After solving a radical equation, check every candidate in the original equation.

Absolute Value

|x| = x, if x ≥ 0
|x| = −x, if x < 0
|x| = a ⟺ x = a or x = −a, for a ≥ 0
|x| = a has no solution when a < 0.
|x| < a ⟺ −a < x < a, for a > 0
|x| ≤ a ⟺ −a ≤ x ≤ a, for a ≥ 0
|x| > a ⟺ x < −a or x > a, for a ≥ 0
|x| ≥ a ⟺ x ≤ −a or x ≥ a, for a ≥ 0

Linear Inequalities

Adding or subtracting the same number on both sides preserves the inequality direction.
Multiplying or dividing both sides by a positive number preserves the inequality direction.
Multiplying or dividing both sides by a negative number reverses the inequality direction.
If a < b, then −a > −b.
For ax + b < c, if a > 0: x < (c − b)/a
For ax + b < c, if a < 0: x > (c − b)/a
The same rules apply to ≤, > and ≥, with the appropriate inequality symbol.

Compound Inequalities

AND: Both inequalities must be true. The solution is the intersection of their solution sets.
OR: At least one inequality must be true. The solution is the union of their solution sets.
For a < x < b, x must be greater than a and less than b.
For x < a or x > b, the solution lies outside the interval between a and b.

2. CONCEPTS

Linear Equations

A linear equation in one variable contains a variable whose highest power is one. Solving it means finding the value of the variable that makes both sides equal.

Rational Coefficients

Equations with rational coefficients contain fractions or rational numbers as coefficients. The LCD can be used to remove fractional coefficients while solving an equation.

Radical Equations

A radical equation contains a variable inside a radical expression. Squaring may help remove a square root, but it can introduce extraneous solutions, so all candidate solutions must be checked in the original equation.

Absolute Value Equations

Absolute value represents the non-negative distance of a number from zero. A positive absolute value equation can produce two possible values, while the zero case produces one value.

Linear Inequalities

An inequality compares two expressions using <, >, ≤ or ≥. Its solution is the set of all values that make the inequality true. Unlike equations, inequalities describe a range of possible values.

Compound Inequalities

An AND compound inequality requires both conditions to be true. An OR compound inequality requires at least one condition to be true.

3. DEFINITIONS

Linear equation: An equation in which the highest power of the variable is one.

Rational coefficient: A coefficient that can be expressed as a ratio of two integers with a non-zero denominator.

Radical equation: An equation in which a variable appears inside a radical expression.

Extraneous solution: A candidate solution obtained during solving that does not satisfy the original equation.

Absolute value: The non-negative distance of a number from zero.

Inequality: A mathematical statement comparing two expressions using symbols such as <, >, ≤ or ≥.

Solution of an inequality: Any value of the variable that makes the inequality true.

Compound inequality: A statement that combines two inequalities using AND or OR.

AND inequality: A compound inequality in which both conditions must be satisfied.

OR inequality: A compound inequality in which at least one condition must be satisfied.

4. KEY POINTS

  • Perform the same valid operation on both sides of an equation.
  • Use the LCD to remove rational coefficients when appropriate.
  • In rational equations, denominators must not equal zero.
  • Squaring a radical equation may introduce extraneous solutions.
  • Always check radical-equation solutions in the original equation.
  • Absolute value represents distance from zero and is never negative.
  • When multiplying or dividing an inequality by a negative number, reverse the inequality sign.
  • Adding or subtracting the same number does not reverse the inequality sign.
  • AND means both conditions must be true.
  • OR means at least one condition must be true.
  • Use interval notation or a number line when representing solution sets, where required.

5. APPLICATION

Linear equations can represent situations involving unknown quantities, costs, totals and equal amounts.

Radical equations may arise in mathematical relationships involving square roots. Candidate solutions must satisfy the original conditions.

Absolute value equations can model distance from a reference value or situations where deviation in either direction matters.

Linear inequalities represent limits and ranges, such as minimum requirements, maximum capacity, budgets and allowable measurements.

Compound inequalities can express a quantity that must remain within a range or satisfy one of several alternative conditions.
