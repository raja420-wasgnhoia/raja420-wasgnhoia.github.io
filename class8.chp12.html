1. FORMULAS & RULES

Basic Data and Frequency

Range:
R = Maximum value − Minimum value
Class Interval Size:
h = Difference between consecutive lower class limits
Class Mark / Midpoint:
x = (Lower class limit + Upper class limit) / 2
Class Boundaries for Integer Data:
Lower boundary = Lower limit − 0.5
Upper boundary = Upper limit + 0.5
Approximate Class Interval:
h = Range / Number of classes
Frequency Rule:
Sum of all frequencies = Total number of observations
Mean:
x̄ = Σx / n

Measures of Dispersion

Range:
R = xmax − xmin
Variance:
S² = Σ(x − x̄)² / n
Shortcut Formula for Variance:
S² = (Σx² / n) − (Σx / n)²
Standard Deviation:
S = √[Σ(x − x̄)² / n]
Shortcut Formula for Standard Deviation:
S = √[(Σx² / n) − (Σx / n)²]

Properties of Variance

Non-negative:
S² ≥ 0
Constant Data:
If all values are equal, S² = 0
Change of Origin:
Var(x ± c) = Var(x)
Change of Scale:
Var(cx) = c² Var(x)
Var(x/c) = Var(x) / c², c ≠ 0

Properties of Standard Deviation

Non-negative:
S ≥ 0
Constant Data:
If all values are equal, S = 0
Change of Origin:
SD(x ± c) = SD(x)
Change of Scale:
SD(cx) = |c| SD(x)
SD(x/c) = SD(x) / |c|, c ≠ 0
Consistency Rule:
Lower standard deviation = Greater consistency

2. CONCEPTS

Types of Data

  • Discrete Data: Countable values obtained by counting.
  • Continuous Data: Measurements that can take any value within a range.
  • Ungrouped Data: Raw data listed individually.
  • Grouped Data: Data arranged into classes with frequencies.

Frequency Distribution

  • Organizes data in a table with frequencies.
  • Common methods: tally marks and direct observation.
  • Usually, 5–15 classes are selected depending on the data.
  • Every fifth tally mark is drawn diagonally across the first four.
  • The sum of frequencies must equal the total observations.
  • The difference between consecutive class marks equals the class interval.

Graphs

  • Line Graph: Points joined by straight line segments; useful for showing change over time.
  • Histogram: Adjacent rectangles representing a continuous frequency distribution.
  • Frequency Polygon: Class marks plotted against frequencies and joined by straight lines.
  • Bar Graph: Compares separate categories using bars.
  • Multiple Bar Graph: Compares two or more related sets of data.
  • Pie Graph: Shows how categories contribute to a whole.

Measures of Dispersion

  • Dispersion describes how spread out the data values are.
  • Two datasets can have the same mean but different dispersions.
  • Range uses only the smallest and largest values.
  • Variance is the mean of squared deviations from the mean.
  • Squaring deviations prevents positive and negative deviations from cancelling.
  • Standard deviation is the positive square root of variance.
  • Standard deviation is expressed in the same unit as the original data.

3. DEFINITIONS

Data: A collection of numerical facts or information about objects or events.

Discrete Data: Data consisting of separate, countable values obtained by counting.

Continuous Data: Data obtained by measurement that can take any value within a given range.

Frequency: The number of times a value occurs or the number of observations in a class.

Frequency Distribution: A tabular arrangement of data showing the frequencies of values or classes.

Grouped Frequency Distribution: A frequency distribution in which data is divided into classes and each class has a frequency.

Class Limits: The lower and upper values that define a class interval.

Class Boundaries: The values that separate consecutive classes without gaps.

Class Interval: The size or width of a class in a frequency distribution.

Class Mark: The midpoint of a class interval.

Line Graph: A graph in which plotted data points are joined by straight line segments.

Histogram: A graph of a continuous frequency distribution using adjacent rectangles.

Frequency Polygon: A graph formed by plotting class marks against frequencies and joining the points with straight lines.

Measure of Central Tendency: A single value that represents the centre of a dataset, such as the mean, median or mode.

Measure of Dispersion: A statistical measure that describes the spread of values around a central value.

Range: The difference between the maximum and minimum values in a dataset.

Variance: The mean of the squared deviations of data values from their mean.

Standard Deviation: The positive square root of variance, measuring the spread of data values around the mean.

Consistency: The degree to which data values or performance results remain close together.

4. KEY POINTS

  • Discrete data is counted; continuous data is measured.
  • Grouped data is arranged into class intervals.
  • For integer classes, boundaries are commonly found by subtracting 0.5 from the lower limit and adding 0.5 to the upper limit.
  • Class marks are the midpoints of their class intervals.
  • Always label graph axes and provide a suitable title.
  • Histogram bars touch because the intervals represent continuous data.
  • A frequency polygon can be drawn over a histogram by joining the midpoints of the tops of the rectangles.
  • Zero-frequency classes are added at both ends when closing a frequency polygon.
  • Choose a graph according to the type of data and the comparison required.
  • Range is simple and quick but depends only on the extreme values.
  • Variance is always non-negative.
  • When all observations are equal, variance and standard deviation are both zero.
  • Adding or subtracting a constant from every value does not change variance or standard deviation.
  • Multiplying every value by a constant multiplies variance by the square of that constant.
  • Multiplying every value by a constant multiplies standard deviation by the absolute value of that constant.
  • Lower standard deviation indicates greater consistency; higher standard deviation indicates greater spread.
  • A higher mean indicates a higher average, not necessarily greater consistency.
