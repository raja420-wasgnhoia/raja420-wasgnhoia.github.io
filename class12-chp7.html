Conic Sections

← Back to Chapters

Definitions

Conic Section: A conic section is a curve obtained by intersecting a plane with a right circular cone.
Circle: The set of all points that are at a fixed distance from a fixed point called the centre.
Parabola: The set of all points equidistant from a fixed point called the focus and a fixed line called the directrix.
Ellipse: The set of all points for which the sum of distances from two fixed points called foci is constant.
Hyperbola: The set of all points for which the difference of distances from two fixed points called foci is constant.
Focus: A fixed point used in defining a conic.
Directrix: A fixed line used in defining a parabola and other conics.
Eccentricity: The ratio of the distance of a point from the focus to its perpendicular distance from the directrix.
Tangent: A line that touches a curve at a point.
Normal: A line perpendicular to the tangent at the point of contact.
Secant: A line that intersects a circle at two points.
Latus Rectum: A focal chord perpendicular to the major axis of an ellipse or transverse axis of a hyperbola.

1. Circle

(x − h)² + (y − k)² = r²
x² + y² = r²
x² + y² + 2gx + 2fy + c = 0
Centre = (−g, −f)
Radius = √(g² + f² − c)
h = −g, k = −f
c = h² + k² − r²
Point circle: g² + f² − c = 0
Real circle: g² + f² − c > 0
Imaginary circle: g² + f² − c < 0
Distance from point (x₀,y₀) to line ax + by + c = 0: d = |ax₀ + by₀ + c| / √(a² + b²)
Distance from centre to line y = mx + c: d = |c| / √(m² + 1)
Two intersections: d < r
Tangent: d = r
No intersection: d > r
Tangent lines to x² + y² = r²: y = mx ± r√(m² + 1)
Tangent to general circle at P(x₁,y₁): (x₁+g)x + (y₁+f)y + gx₁ + fy₁ + c = 0
Tangent slope: dy/dx = −(x₁+g)/(y₁+f)
Normal slope: (y₁+f)/(x₁+g)
Tangent length from external point: PA = √(x₁² + y₁² + 2gx₁ + 2fy₁ + c)

2. Parabola

y² = 4ax
y² = −4ax
x² = 4ay
x² = −4ay
Focus of y² = 4ax: (a,0)
Directrix of y² = 4ax: x = −a
Eccentricity: e = 1
Latus rectum length: 4a
Vertex form: (y − k)² = 4a(x − h)
General parabola y = Ax² + Bx + C: h = −B/(2A)
For y = Ax² + Bx + C: k = −(B² − 4AC)/(4A)
For (y − k)² = 4a(x − h): dy/dx = 2a/(y − k)
Tangent at P(x₁,y₁): 2a(x − x₁) − (y₁ − k)(y − y₁) = 0
Normal at P(x₁,y₁): (y₁ − k)(x − x₁) + 2a(y − y₁) = 0
Tangent to y² = 4ax: y = mx + a/m

3. Ellipse

x²/a² + y²/b² = 1
y²/a² + x²/b² = 1
b² = a² − c²
Eccentricity: e = c/a
e = √(a² − b²)/a
b² = a²(1 − e²)
Horizontal foci: (±c,0)
Vertical foci: (0,±c)
Latus rectum length: 2b²/a
Horizontal directrices: x = ±a/e = ±a²/c
Vertical directrices: y = ±a/e = ±a²/c
Shifted horizontal ellipse: (x − h)²/a² + (y − k)²/b² = 1
Shifted vertical ellipse: (x − h)²/b² + (y − k)²/a² = 1
Tangent at P(x₁,y₁): (x₁−h)(x−h)/a² + (y₁−k)(y−k)/b² = 1
Tangent at origin-centred ellipse: x₁x/a² + y₁y/b² = 1
Tangent slope: dy/dx = −b²(x−h) / [a²(y−k)]
Normal slope: a²(y₁−k) / [b²(x₁−h)]
Tangency condition: D = 0
Tangent from origin: y = mx ± √(a²m² + b²)

4. Hyperbola

x²/a² − y²/b² = 1
y²/a² − x²/b² = 1
c² = a² + b²
Eccentricity: e = c/a
e > 1
Horizontal foci: (±c,0)
Vertical foci: (0,±c)
Horizontal latus rectum: 2b²/a
Horizontal directrices: x = ±a/e = ±a²/c
Vertical directrices: y = ±a/e = ±a²/c
Shifted horizontal hyperbola: (x − h)²/a² − (y − k)²/b² = 1
Shifted vertical hyperbola: (y − k)²/a² − (x − h)²/b² = 1
Tangent from origin: y = mx ± √(a²m² − b²)
Tangent at P(x₁,y₁): x₁x/a² − y₁y/b² = 1
Tangent slope: dy/dx = b²x / (a²y)
Normal slope: −a²y₁ / (b²x₁)
Normal at P(x₁,y₁): a²y₁(x−x₁) + b²x₁(y−y₁) = 0
Tangency condition: D = 0

Key Points

• A circle has eccentricity e = 0.
• A parabola has eccentricity e = 1.
• An ellipse has 0 < e < 1.
• A hyperbola has e > 1.
• For a parabola, the vertex-to-focus distance is a.
• For an ellipse, a > b and a > c.
• For a hyperbola, c² = a² + b².
• For an ellipse, b² = a² − c².
• Tangent and radius are perpendicular at the point of contact.
• A tangent gives one repeated intersection, so D = 0.
• For a secant, D > 0.
• For no real intersection, D < 0.
• Completing the square is used to convert general conic equations into standard form.
• The centre of an ellipse or hyperbola is the midpoint of its two foci.
• In an ellipse, the sum of distances from the two foci is constant.
• In a hyperbola, the difference of distances from the two foci is constant.
• The major/transverse axis passes through the foci.
