Formulas

|A| = a11a22 − a21a12
|A| = a11(a22a33 − a23a32) − a12(a21a33 − a23a31) + a13(a21a32 − a22a31)
A−1 = 1/|A| adj(A)
adj(A) = (−1)i+j |A|

📌 Key Points

• If A is a square matrix, then order of A and At is same.

• For square matrix A, if A = At, then A is a symmetric matrix.

• For square matrix A, if A = −At, then A is a skew symmetric matrix.

• If |A| = 0, then matrix is singular.

• If |A| ≠ 0, then matrix is non-singular.

• A−1 ≠ 1/A.

• (AB)−1 = B−1A−1 is known as reversal law of inverse.
