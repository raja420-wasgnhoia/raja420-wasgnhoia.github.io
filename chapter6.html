Formulas

n! = n(n − 1)(n − 2) ··· 1
0! = 1
(n + 1)! = (n + 1)n!
ⁿPᵣ = n!/(n − r)!
ⁿPₙ = n!
Permutation of alike objects = n!/(n₁! n₂! ··· nₖ!)
Circular permutation = (n − 1)!
ⁿCᵣ = n!/[r!(n − r)!]
ⁿCᵣ = ⁿPᵣ/r!
ⁿC₀ = 1
ⁿCₙ = 1
ⁿC₁ = n
ⁿCᵣ = ⁿCₙ₋ᵣ
ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ
r · ⁿCᵣ = n · ⁿ⁻¹Cᵣ₋₁

📌 Key Points

• In permutation, order matters.

• In combination, order does not matter.

• ⁿPᵣ ≥ ⁿCᵣ for the relevant positive values of r.

• (n + n)! ≠ n! + n!

• (n × n)! ≠ n! × n!

• If r = n, then ⁿPₙ = n!

• If objects are alike, divide by n₁! n₂! ···

• In a line arrangement = n!

• In a circular arrangement = (n − 1)!

• ⁿC₀ = 1 and ⁿCₙ = 1
