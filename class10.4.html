Important Formulas

1. Trichotomy Property
For any two real numbers a and b, exactly one of the following is true:
a < b,   a > b,   a = b
2. Addition Property of Inequality
If a > b, then a + c > b + c.
If a < b, then a + c < b + c.
3. Subtraction Property of Inequality
If a > b, then a − c > b − c.
If a < b, then a − c < b − c.
4. Multiplication Property
If c > 0 and a < b, then ac < bc.
If c < 0 and a < b, then ac > bc.
5. Division Property
If c > 0, the inequality sign remains unchanged.
If c < 0, the inequality sign is reversed.
6. Graph Symbols
< or > → Open circle
≤ or ≥ → Closed circle
7. Boundary Line
For y = mx + c, the line y = mx + c is the boundary line.
8. Boundary Line Rule
≤ or ≥ → Solid line
< or > → Dashed line
9. Quadratic Inequality
ax² + bx + c > 0
ax² + bx + c < 0
ax² + bx + c ≥ 0
ax² + bx + c ≤ 0
10. Absolute Value
|x| = x, when x ≥ 0
|x| = −x, when x < 0
11. Absolute Value Property
|x| ≥ 0
12. Absolute Value Equation
|x| = a → x = a or x = −a, for a ≥ 0
13. Negative Absolute Value
|x| = a, where a < 0 → No solution
14. Absolute Inequality
|x| < a → −a < x < a
15. Absolute Inequality
|x| ≤ a → −a ≤ x ≤ a
16. Absolute Inequality
|x| > a → x < −a or x > a
17. Absolute Inequality
|x| ≥ a → x ≤ −a or x ≥ a

Definitions

Linear Inequality: An inequality involving a first-degree expression in one or more variable

Quadratic Inequality: An inequality involving a second-degree expression.

Linear Inequality in Two Variables: An inequality obtained by replacing the equality sign in a linear equation with <, >, ≤ or ≥

Solution of an Inequality: An ordered pair (x, y) that makes the inequality a true statement.

Boundary Line: The line that divides the plane into two regions while graphing an inequality.

Feasible Region: The region containing all points that satisfy the given inequalities.

Absolute Value: The absolute value of a number is its distance from zero on the number line.

System of Linear Inequalities: Two or more linear inequalities involving the same variables.

Key Points

  • Inequality Sign: When multiplying or dividing an inequality by a negative number, reverse the inequality sign.
  • Open Circle: Used for < and > because the endpoint is not included.
  • Closed Circle: Used for ≤ and ≥ because the endpoint is included.
  • Quadratic Inequalities: Critical points divide the number line into intervals. Test one point from each interval to determine the solution.
  • Two-Variable Inequalities: First draw the boundary line, then use a test point to determine the region to shade.
  • Absolute Value: Absolute value represents distance from zero and is always non-negative.
  • Absolute Inequalities: Less-than inequalities give the interval between two values.
    Greater-than inequalities give the regions outside two values.
  • System of Inequalities: The solution of a system is the intersection of the solution regions of all inequalities.
  • Test Point: If the test point satisfies the inequality, shade the region containing that point. Otherwise, shade the opposite region

Most Important Things

  • Negative multiplication or division → Reverse the inequality sign.
  • ≤ or ≥ → Closed Circle + Solid Line.
  • < or > → Open Circle + Dashed Line.
  • |x| ≤ a → −a ≤ x ≤ a.
  • |x| ≥ a → x ≤ −a or x ≥ a.
  • |x| ≥ 0 always.
  • Two-variable inequality → Boundary Line + Test Point + Shading.
  • System of inequalities → Intersection of solution regions.
  • Quadratic inequality → Critical Points + Intervals + Test Points.
