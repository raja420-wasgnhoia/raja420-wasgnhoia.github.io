FORMULAS & RULES

A. Frequency Distribution

1. Frequency:
Frequency = Number of times an observation occurs in the data.
2. Total Frequency:
Total frequency = Sum of all class frequencies.
Σf = f₁ + f₂ + f₃ + ⋯
3. Class Interval Size:
h = Difference between two consecutive lower class limits, or two consecutive upper class limits.
4. Class Mid-value:
x = (Lower class limit + Upper class limit) / 2
5. Class Frequency:
Class frequency = Number of observations that fall within a class interval.

B. Mean of Ungrouped Data

6. Arithmetic Mean:
x̄ = Sum of all observations / Number of observations
7. Mean Formula:
x̄ = (x₁ + x₂ + x₃ + ⋯ + xₙ) / n
x̄ = Σx / n
8. Summation Symbol:
Σx represents the sum of all observations, and n is the total number of observations.

C. Mean of Grouped Data

9. Class Mid-value:
x = (Lower limit + Upper limit) / 2
10. Product of Frequency and Mid-value:
fx = f × x
11. Mean of Grouped Data:
x̄ = Σfx / Σf
Here, f is the class frequency and x is the class mid-value.

D. Median

12. Median for Odd Number of Observations:
First arrange the data in ascending order.
Middle position = (n + 1) / 2
The observation in this position is the median.
13. Median for Even Number of Observations:
Median = (First middle value + Second middle value) / 2

E. Mode

14. Mode:
Mode = The value that occurs most frequently in a data set.
15. Bimodal Data:
A data set is bimodal when two values share the highest frequency.

F. Percentages and Pie Graphs

16. Percentage:
Percentage = (Part / Whole) × 100%
17. Find a Part from a Percentage:
Part = (Percentage / 100) × Total
18. Percentage of a Category:
Category percentage = (Category frequency / Total frequency) × 100%
19. Pie Graph Sector Angle:
Sector angle = (Category frequency / Total frequency) × 360°
20. Total Angle of a Pie Graph:
The sum of all sector angles is 360°.

G. Data and Units

21. Range of Data:
Range = Highest value − Lowest value
22. Relative Frequency:
Relative frequency = Frequency / Total frequency
23. Frequency Percentage:
Frequency percentage = (f / Σf) × 100%

CONCEPTS

1. Data Collection and Presentation

Data may be collected directly from relevant departments, through people and media, questionnaires, surveys, sampling, and digital or electronic sources.
Data should be organized and presented clearly so that patterns, comparisons and trends can be understood.
Common ways of presenting data include tables, pictograms, pie graphs, bar graphs, line graphs and histograms.

2. Types of Data

Ungrouped Data: Data recorded as individual observations without arranging them into classes.
Grouped Data: Data organized into classes or intervals with their corresponding frequencies.
Raw Data: Data in its original collected form before systematic organization.

3. Frequency Distribution

A frequency distribution organizes observations into classes and records how many observations fall into each class.
A class interval has a lower class limit and an upper class limit. The number of classes depends on the data and the purpose of the analysis.
Class intervals should cover the data without accidentally omitting observations or counting the same observation twice.

4. Measures of Central Tendency

Mean: The arithmetic average of all observations.
Median: The middle value after arranging the observations in ascending or descending order.
Mode: The value that occurs most often.
The mean uses every observation, the median identifies the centre of ordered data, and the mode identifies the most frequent value.
For grouped data, each class is represented by its mid-value when calculating an approximate mean.
The mean calculated from grouped data is generally an approximation because the individual values within each class are not known.

5. Pie Graphs

A pie graph is a circle divided into sectors. Each sector represents a category's share of the whole.
The size of a sector is proportional to its category's frequency or percentage. A larger sector represents a larger share.

6. Bar Graphs

A bar graph compares categories using bars of different heights or lengths. Bars are usually separated by spaces.
The category labels are placed along one axis and the corresponding frequencies or values along the other axis.

7. Histograms

A histogram represents a frequency distribution using adjacent rectangles. There are no gaps between neighbouring bars for continuous class intervals.
The horizontal axis shows class intervals or observations, while the vertical axis shows frequency.
For equal-width classes, the heights of histogram bars can be compared directly with frequencies. More generally, bar area represents frequency.

8. Choosing a Diagram

Choose a graph according to the type of data and the purpose of the presentation. Pie graphs show proportions, bar graphs compare categories, and histograms display frequency distributions.

DEFINITIONS

Data: Numerical information or facts collected through observations, measurements, surveys or other sources.
Statistics: The study of collecting, organizing, presenting, analysing and interpreting data.
Climatology: The study of climate in a particular area over a long period of time.
Observation: A single recorded value or item in a data set.
Raw Data: Data in its original form before systematic arrangement.
Ungrouped Data: Data presented as individual observations rather than grouped into class intervals.
Grouped Data: Data organized into classes or intervals with corresponding frequencies.
Frequency: The number of times an observation occurs in a data set.
Frequency Distribution: A tabular arrangement of data into classes with their respective frequencies.
Class Interval: A range of values used to group observations in a frequency distribution.
Lower Class Limit: The smallest stated value of a class interval.
Upper Class Limit: The largest stated value of a class interval.
Class Width: The width of a class interval, found from the difference between consecutive class limits when intervals have equal width.
Class Mid-value: The average of the lower and upper class limits.
Mean: The sum of all observations divided by the total number of observations.
Median: The middle value of ordered data; for an even number of observations, it is the average of the two middle values.
Mode: The value that occurs most frequently in a data set.
Bimodal Data: Data with two values that share the highest frequency.
Pie Graph: A circular diagram divided into sectors representing parts of a whole.
Bar Graph: A diagram that uses separated rectangular bars to compare categories.
Histogram: A graph that displays a frequency distribution using adjacent rectangles.

KEY POINTS

1. Always check the number of observations before calculating the mean or median.
2. Arrange data in ascending order before finding the median.
3. For an odd number of observations, the median is the single middle value.
4. For an even number of observations, the median is the average of the two middle values.
5. A data set can have one mode, more than one mode, or no single most frequent value.
6. Mean of ungrouped data is calculated using all the individual observations.
7. For grouped data, find each class mid-value first, then calculate fx.
8. The grouped mean is calculated by dividing Σfx by Σf.
9. The total frequency equals the total number of observations represented by the frequency table.
10. The sum of all percentages in a complete data set is 100%.
11. The sum of all pie graph sector angles is 360°.
12. In a pie graph, the largest sector represents the largest share of the total.
13. Bar graphs are useful for comparing separate categories.
14. Histogram bars touch each other because they represent continuous intervals or adjoining classes.
15. For equal-width histogram classes, bar height is proportional to frequency. For unequal widths, frequency density is used so that bar area represents frequency.
16. The class interval size should be consistent when equal-width classes are required.
17. A clear title, suitable scale, labelled axes and accurate data make graphs easier to interpret.
18. Data handling helps people compare information, identify trends, plan budgets and make informed decisions.
