FORMULAS & NOTATION

Union: A ∪ B = {x : x ∈ A or x ∈ B}
Intersection: A ∩ B = {x : x ∈ A and x ∈ B}
Difference: A − B = {x : x ∈ A and x ∉ B}
Complement: A′ = U − A
Commutative Law of Union: A ∪ B = B ∪ A
Commutative Law of Intersection: A ∩ B = B ∩ A
Associative Law of Union: (A ∪ B) ∪ C = A ∪ (B ∪ C)
Associative Law of Intersection: (A ∩ B) ∩ C = A ∩ (B ∩ C)
Distributive Law: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
Distributive Law: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
De Morgan's First Law: (A ∪ B)′ = A′ ∩ B′
De Morgan's Second Law: (A ∩ B)′ = A′ ∪ B′
Disjoint Sets: A ∩ B = ∅
Subset Property: If A ⊆ B, then A ∩ B = A and A ∪ B = B
Number of Subsets: If n(A) = n, then n(P(A)) = 2ⁿ
Empty Set: ∅ ⊆ A
Universal Set: A ⊆ U

CONCEPTS

Representation of Sets: Sets can be represented by descriptive form, roster form and set-builder form.
Natural Numbers (N): The set of counting numbers.
Whole Numbers (W): Natural numbers together with zero.
Integers (Z): Positive numbers, negative numbers and zero.
Even Numbers (E): Integers divisible by 2.
Odd Numbers (O): Integers not divisible by 2.
Prime Numbers (P): Natural numbers greater than 1 having exactly two distinct positive factors.
Power Set: The set containing all subsets of a given set, including the empty set and the set itself.
Universal Set: The set containing all elements under consideration.
Union of Sets: Contains all elements belonging to either set or both sets.
Intersection of Sets: Contains only the elements common to both sets.
Difference of Sets: Contains elements of the first set that do not belong to the second set.
Complement of a Set: Contains the elements of the universal set that do not belong to the given set.
Venn Diagrams: Diagrams using closed curves to represent sets and their relationships.
Set Operations: Union, intersection, difference and complement are the main operations on sets.
Distributive Laws: Intersection distributes over union, and union distributes over intersection.

DEFINITIONS

Set: A well-defined collection of distinct objects.
Universal Set: A set containing all the elements under consideration.
Subset: A set A is a subset of B if every element of A belongs to B.
Power Set: The set of all subsets of a given set.
Union: The set of all elements belonging to either of the given sets or both.
Intersection: The set of elements common to the given sets.
Difference: The set of elements belonging to one set but not the other.
Complement: The set of elements in the universal set that are not in the given set.
Disjoint Sets: Sets having no common elements.
Venn Diagram: A diagram that represents sets and their relationships using closed curves.
De Morgan's Laws: Laws relating the complement of a union or intersection to the complements of the sets.

KEY POINTS

Sets can be represented using descriptive, roster and set-builder forms.
Set elements are written inside curly brackets { }.
The symbol ∈ means “belongs to” and ∉ means “does not belong to”.
The symbol ⊆ represents a subset, while ∅ represents the empty set.
Union is represented by ∪ and intersection by ∩.
Set difference is represented by − and complement by ′.
The power set contains every possible subset of a set.
A set with n elements has 2ⁿ subsets.
Venn diagrams help represent set operations and relationships visually.
De Morgan's laws are used to simplify complements of unions and intersections.
