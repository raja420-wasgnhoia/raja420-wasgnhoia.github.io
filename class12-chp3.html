Important Formulas & Definitions

1. Antiderivative / Indefinite Integral
F′(x) = f(x) → F(x) is an anti-derivative of f(x)
∫ f(x) dx = F(x) + c
2. Formula 3.1 — Power Rule
∫ xⁿ dx = xⁿ⁺¹/(n+1) + c,  n ≠ −1
∫ [f(x)]ⁿf′(x)dx = [f(x)]ⁿ⁺¹/(n+1) + c
3. Formula 3.2 — Log Rule
∫ 1/x dx = ln|x| + c
∫ f′(x)/f(x) dx = ln|f(x)| + c
4. Formula 3.3 — Exponential eˣ
∫ eˣ dx = eˣ + c
∫ ef(x)f′(x)dx = ef(x) + c
5. Formula 3.4 — Exponential aˣ
∫ aˣ dx = aˣ/ln(a) + c,  a > 0, a ≠ 1
∫ af(x)f′(x)dx = af(x)/ln(a) + c
6. Theorem 3.1 — Properties of Indefinite Integrals
∫ cf(x)dx = c∫f(x)dx
∫[f(x)+g(x)]dx = ∫f(x)dx + ∫g(x)dx
∫[f(x)−g(x)]dx = ∫f(x)dx − ∫g(x)dx
∫[af(x) ± bg(x)]dx = a∫f(x)dx ± b∫g(x)dx
7. 3.2 — Trigonometric Integration
∫ cos x dx = sin x + c
∫ sin x dx = −cos x + c
∫ cos(kx)dx = sin(kx)/k + c
∫ sin(kx)dx = −cos(kx)/k + c
∫ sec²x dx = tan x + c
∫ csc²x dx = −cot x + c
∫ sec x tan x dx = sec x + c
∫ csc x cot x dx = −csc x + c
∫ sec x dx = ln|sec x + tan x| + c
∫ csc x dx = ln|csc x − cot x| + c
∫ tan x dx = ln|sec x| + c
∫ cot x dx = ln|sin x| + c
sin²x = (1 − cos2x)/2
cos²x = (1 + cos2x)/2
8. Substitution Method
t = g(x),  dt = g′(x)dx
∫f(g(x))g′(x)dx = ∫f(t)dt
9. Standard Integration Forms — 3.5 to 3.9
∫ dx/√(a²−x²) = sin⁻¹(x/a) + c
∫√(a²−x²)dx = x√(a²−x²)/2 + (a²/2)sin⁻¹(x/a) + c
∫dx/√(x²−a²) = ln|x+√(x²−a²)| + c
∫dx/√(x²+a²) = ln|x+√(x²+a²)| + c
∫dx/(a²+x²) = (1/a)tan⁻¹(x/a) + c
∫√(a²+x²)dx = x√(a²+x²)/2 + (a²/2)ln|x+√(a²+x²)| + c
∫√(x²−a²)dx = x√(x²−a²)/2 − (a²/2)ln|x+√(x²−a²)| + c
10. 3.4 — Integration by Parts
∫u dv = uv − ∫v du
∫f·g dx = f∫g dx − ∫[f′(x)∫g dx]dx
ILATE order: Inverse → Logarithmic → Algebraic/Power → Trigonometric → Exponential
11. 3.5 — Partial Fractions
Proper rational function: deg P(x) < deg Q(x)
If deg P ≥ deg Q: first perform polynomial division.
Form 1: 1/[(x+a)(x+b)] = A/(x+a) + B/(x+b)
Form 2: 1/(x+a)³ = A/(x+a) + B/(x+a)² + C/(x+a)³
Form 3: 1/[(x+a)(x²+1)] = A/(x+a) + (Bx+C)/(x²+1)
∫dx/(x+a) = ln|x+a| + c
∫dx/(x²+1) = tan⁻¹x + c
12. Other Standard Results
∫eaxsin(bx)dx = eax[a sin(bx) − b cos(bx)]/(a²+b²) + c
∫eaxcos(bx)dx = eax[a cos(bx) + b sin(bx)]/(a²+b²) + c
13. 3.6 — Definite Integral
Δx = (b−a)/n
a = x₀ < x₁ < ... < xₙ = b
Δxₖ = xₖ − xₖ₋₁
A ≈ Σ f(xₖ)Δxₖ
A = lim Δx→0 Σ f(xₖ)Δxₖ
∫ₐᵇf(x)dx = lim Δx→0 Σf(xₖ)Δxₖ
14. 3.7 — Properties of Definite Integrals
∫ₐᵃf(x)dx = 0
∫ᵦᵃf(x)dx = −∫ₐᵇf(x)dx
∫ₐᵇf(x)dx = ∫ₐᶜf(x)dx + ∫ᶜᵇf(x)dx
∫ₐᵇ cf(x)dx = c∫ₐᵇf(x)dx
∫ₐᵇ[f(x) ± g(x)]dx = ∫ₐᵇf(x)dx ± ∫ₐᵇg(x)dx
∫ₐᵇ[cf(x) ± dg(x)]dx = c∫ₐᵇf(x)dx ± d∫ₐᵇg(x)dx
15. 3.8 — Fundamental Theorem of Calculus
A(x) = ∫ₐˣf(t)dt
A(a) = 0
A′(x) = f(x)
F(x) = A(x) + c
∫ₐᵇf(x)dx = F(b) − F(a) = [F(x)]ₐᵇ
16. Definite Integration Methods
Method 1 — Substitution without changing limits:
Put u = g(x), integrate in u, convert back to x, then apply original x-limits.
Method 2 — Substitution with changing limits:
Convert the lower and upper x-limits into u-limits and integrate directly using u.
17. 3.9 / 3.10 — Area
f(x) ≥ 0 → A = ∫ₐᵇf(x)dx
Area between curves = ∫ₐᵇ[f(x)−g(x)]dx
Intersection: Solve f(x) = g(x) to find the limits.
Below x-axis: The definite integral is negative. Geometric area is taken as positive.
18. 3.11 — Volume by Disc Method
V = πr²h
V ≈ Σπ[f(xₖ)]²Δxₖ
X-axis rotation: V = π∫ₐᵇ[f(x)]²dx
Y-axis rotation: V = π∫ₐᵇ[g(y)]²dy
If y = √x: x = y² = g(y)
19. 3.12.1 — Consumer & Producer Surplus
Equilibrium: D(x) = S(x)
Equilibrium price: x = p
D(b) = 0 → demand becomes zero
S(c) = 0 → supply becomes zero
Consumer Surplus: Cs = ∫ₚᵇD(x)dx
Producer Surplus: Ps = ∫ᶜₚS(x)dx
20. 3.12.2 — Rectilinear Motion
v(t) = dS/dt
a(t) = dv/dt
S(t) = ∫v(t)dt

Key Points

  • Integration, differentiation ka reverse process hai.
  • Indefinite integral mein +c add karna zaroori hota hai.
  • Constant ko integration se bahar nikala ja sakta hai.
  • Power rule mein power mein 1 add karke new power se divide karte hain.
  • Logarithmic integration mein absolute value ka khayal rakha jata hai.
  • Trigonometric integrals solve karne ke liye standard formulas use hote hain.
  • Substitution method tab useful hota hai jab function ke saath uska derivative bhi maujood ho.
  • Integration by parts product of functions ke integration ke liye use hota hai.
  • ILATE function choose karne ka order hai: Inverse, Logarithmic, Algebraic, Trigonometric, Exponential.
  • Partial fractions rational functions ko simpler fractions mein divide karne ka method hai.
  • Definite integral ka result ek fixed value hota hai.
  • Fundamental Theorem of Calculus definite integral ko antiderivative se connect karta hai.
  • Area between two curves mein upper function se lower function subtract karte hain.
  • Disc method se axis ke around rotation wale solid ka volume find kiya jata hai.
  • Distance find karte waqt velocity ke sign ka khayal rakhna zaroori hai.
  • Variable force ke liye work ko integration se find kiya jata hai.
