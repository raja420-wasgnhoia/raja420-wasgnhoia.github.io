FORMULAS / RULES / CONCEPTS

1. Rounding to the Nearest 10, 100 and 1000

Nearest 10:
  • Examine the ones digit.
  • If it is 0–4, keep the tens digit unchanged and replace the ones digit with 0.
  • If it is 5–9, increase the tens digit by 1 and replace the ones digit with 0.
Nearest 100:
  • Examine the tens digit.
  • If it is 0–4, replace the tens and ones digits with 0.
  • If it is 5–9, increase the hundreds digit by 1 and replace the tens and ones digits with 0.
Nearest 1000:
  • Examine the hundreds digit.
  • If it is 0–4, replace the hundreds, tens and ones digits with 0.
  • If it is 5–9, increase the thousands digit by 1 and replace the last three digits with 0.

2. Estimating Calculations

Estimated sum: Round each number to a suitable place value, then add.
Estimated difference: Round each number to a suitable place value, then subtract.
Estimated product: Round each factor to a suitable place value, then multiply.
Estimated quotient: Round the dividend and divisor to suitable place values, then divide.
Reasonable estimate: Choose a rounding level that gives an estimate close enough to the actual answer for the situation.

3. Rounding Decimals

Nearest whole number: Examine the tenths digit. If it is 0–4, keep the ones digit unchanged. If it is 5–9, increase the ones digit by 1. Remove the decimal part.
Nearest tenth (1 decimal place): Examine the hundredths digit. If it is 0–4, keep the tenths digit unchanged. If it is 5–9, increase the tenths digit by 1. Remove later digits.
Nearest hundredth (2 decimal places): Examine the thousandths digit. If it is 0–4, keep the hundredths digit unchanged. If it is 5–9, increase the hundredths digit by 1. Remove later digits.

4. Significant Figures

Rules for counting significant figures:
  • All non-zero digits are significant.
  • Zeros between significant digits are significant.
  • Zeros before the first non-zero digit are not significant.
  • Trailing zeros to the right of a decimal point are significant.
Rounding to a required number of significant figures:
  1. Start counting from the first non-zero digit.
  2. Keep the required number of significant digits.
  3. Examine the next digit: 0–4 means keep the last retained digit unchanged; 5–9 means increase it by 1.
  4. For whole numbers, replace removed place values with zeros when needed.

5. Circle and Approximation Error

Diameter: d = 2r
Circumference-to-diameter ratio: C/d = π
Area of a circle: A = πr², using π ≈ 22/7 when appropriate.
Measurement correct to the nearest unit: Actual value is at least 0.5 unit below the rounded value and less than 0.5 unit above it.
Nearest centimetre bounds: Rounded value − 0.5 cm ≤ actual value < rounded value + 0.5 cm.
Approximation error: Difference between an approximate value and the relevant actual or calculated value.

CONCEPTS

1. Estimation and Rounding Off

Estimation gives a useful rough value when an exact figure is unnecessary or difficult to know. Rounding off changes a number to a nearby value at a chosen place value or accuracy.

Numbers can be rounded to the nearest 10, 100, 1000 and so on, to a required number of decimal places, or to a specified number of significant figures.

2. Estimating Sums, Differences, Products and Quotients

Round the numbers before carrying out the calculation. The place value chosen depends on the purpose of the estimate. A reasonable estimate should be sufficiently close to the actual result.

3. Significant Figures

Significant figures are the digits that communicate the precision of a measured or stated number. Non-zero digits are significant; zeros between significant digits and trailing zeros after a decimal point are also significant. Leading zeros only show the position of the decimal point and are not significant.

4. Approximation Error and Bounds

An error in an approximate measurement can affect a result calculated from it. To estimate the possible error in a calculation, consider the lower and upper bounds of the original measurement and how those bounds affect the result.

If a value is rounded to the nearest unit, the possible actual value extends from 0.5 unit below the rounded value (inclusive) to 0.5 unit above it (exclusive).

DEFINITIONS

1. Budget

A budget is an estimate of income and expenditure for a set period of time. It reflects financial and economic responsibilities and helps plan future activities.

2. Estimation / Rounding Off

Estimation is finding a value close to the actual value when an exact answer is not necessary. Rounding off is expressing a number as a nearby value at a specified level of accuracy.

3. Approximation

To approximate means to give a rough answer that may be slightly more or less than the actual answer.

4. Significant Figures

Significant figures are the digits in a number that provide information about its precision.

5. Approximation Error

Approximation error is the difference between an approximate value and the corresponding actual value or more accurate calculated value.

KEY POINTS

  • For nearest tens, check the ones digit.
  • For nearest hundreds, check the tens digit.
  • For nearest thousands, check the hundreds digit.
  • Digits 0–4 round down; digits 5–9 round up.
  • To round to the nearest whole number, check the tenths digit.
  • To round to one decimal place, check the hundredths digit.
  • To round to two decimal places, check the thousandths digit.
  • Leading zeros are not significant.
  • Zeros between non-zero digits are significant.
  • Trailing zeros to the right of a decimal point are significant.
  • Begin counting significant figures at the first non-zero digit.
  • For a value correct to the nearest unit, use bounds of ±0.5 unit.
  • When estimating calculations, choose place values that make the estimate useful and reasonable.
