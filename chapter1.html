Formulas

z = x + iy
|z| = √(x² + y²)
z̄ = x − iy
|z|² = x² + y²
x² + y² = r²
r = √(x² + y²)
x/r = cos θ
x = r cos θ
y/r = sin θ
y = r sin θ
z = r(cos θ + i sin θ)
z₁/z₂ = (r₁/r₂)[cos(θ₁ − θ₂) + i sin(θ₁ − θ₂)]
x = xₘₐₓeiθ
E = IZ
I = E/Z
Z = E/I

📌 Key Points

• i = √−1

• i² = −1

• z̄₁z̄₂ = z̄₁z̄₂

• z̄₁/z̄₂ = z̄₁/z̄₂

• x = Real part

• y = Imaginary part

• |z₁z₂| = |z₁||z₂|

• |z₁/z₂| = |z₁|/|z₂|

• Re(z₁)Re(z₂) ≠ Re(z₁z₂)

• Im(z₁)Im(z₂) ≠ Im(z₁z₂)

• θ = arg(z)

• cos θ + i sin θ = eiθ — Euler's Formula

• sin(θ + 2kπ) = sin θ

• cos(θ + 2kπ) = cos θ

• arg(z₁z₂) = arg(z₁) + arg(z₂)

• arg(z₁/z₂) = arg(z₁) − arg(z₂)
