Important Formulas

Order of Matrix: Order = Number of rows × Number of columns
Transpose: If A is m × n, then Aᵀ is n × m
Transpose Property: (Aᵀ)ᵀ = A
Symmetric Matrix: A = Aᵀ
Skew-Symmetric Matrix: A = −Aᵀ
Additive Identity: A + O = O + A = A
Additive Inverse: A + (−A) = O
Commutative Law of Addition: A + B = B + A
Associative Law of Addition: (A + B) + C = A + (B + C)
Scalar Multiplication: k(A + B) = kA + kB
Scalar Property: (h + k)A = hA + kA
Scalar Property: (hk)A = h(kA)
Matrix Multiplication Condition: Columns of A = Rows of B
Order of Product: If A is m × n and B is n × p, then AB is m × p
Associative Law of Multiplication: (AB)C = A(BC)
Distributive Law: A(B + C) = AB + AC
Distributive Law: A(B − C) = AB − AC
Right Distributive Law: (A + B)C = AC + BC
Identity Matrix: AI = IA = A
Zero Matrix: AO = OA = O
Determinant of 2 × 2 Matrix: |A| = ad − bc
Singular Matrix: |A| = 0
Non-Singular Matrix: |A| ≠ 0
Adjoint: adj A = [ d −b ; −c a ]
Inverse of Matrix: A⁻¹ = (1/|A|) adj A
Inverse Property: A⁻¹A = AA⁻¹ = I
Inverse Property: (A⁻¹)⁻¹ = A

Definitions

  • Matrix: A rectangular arrangement of numbers in rows and columns.
  • Element / Entry: Each number in a matrix is called an element or entry.
  • Order of Matrix: The number of rows and columns of a matrix, written as m × n.
  • Row Matrix: A matrix having only one row.
  • Column Matrix: A matrix having only one column.
  • Rectangular Matrix: A matrix in which the number of rows is not equal to the number of columns.
  • Square Matrix: A matrix in which the number of rows is equal to the number of columns.
  • Null / Zero Matrix: A matrix in which all elements are zero.
  • Diagonal Matrix: A square matrix in which all elements except the principal diagonal elements are zero.
  • Scalar Matrix: A diagonal matrix in which all principal diagonal elements are equal and non-zero.
  • Identity Matrix: A scalar matrix in which all principal diagonal elements are 1.
  • Transpose: A matrix obtained by changing rows into columns and columns into rows.
  • Symmetric Matrix: A square matrix for which A = Aᵀ.
  • Skew-Symmetric Matrix: A square matrix for which A = −Aᵀ.
  • Determinant: A number associated with a square matrix.
  • Singular Matrix: A square matrix whose determinant is zero.
  • Non-Singular Matrix: A square matrix whose determinant is non-zero.
  • Adjoint: The matrix obtained by interchanging principal diagonal elements and changing the signs of secondary diagonal elements.
  • Inverse Matrix: A matrix A⁻¹ such that A⁻¹A = AA⁻¹ = I.
  • Invertible Matrix: A matrix whose inverse exists.
  • Cramer's Rule: A method for solving simultaneous linear equations using determinants.

Key Points

  • Order of a matrix is written as rows × columns.
  • Two matrices can be added or subtracted only if they have the same order.
  • Matrix multiplication is possible when columns of the first matrix equal rows of the second matrix.
  • The order of AB is determined by the outer dimensions.
  • Matrix multiplication is generally not commutative: AB ≠ BA.
  • Every symmetric matrix is square.
  • Every diagonal matrix is square.
  • The identity matrix is always square.
  • Only square matrices have determinants.
  • A determinant is a number, not a matrix.
  • If |A| = 0, the matrix is singular.
  • If |A| ≠ 0, the matrix is non-singular.
  • The inverse of a matrix exists only when |A| ≠ 0.
  • The inverse of a matrix, if it exists, is unique.
  • A⁻¹A = AA⁻¹ = I.
  • In (AB)⁻¹ = B⁻¹A⁻¹, the order is reversed.
  • For Cramer's Rule, D must not be zero.
  • In Cramer's Rule, Dₓ replaces the first column and Dᵧ replaces the second column.
  • For AX = B, the inverse method gives X = A⁻¹B.
  • For conformable matrices, multiplication by the identity matrix leaves the matrix unchanged.
