1. FORMULAS & NOTATION

Rational Numbers:
Q = {a/b : a, b ∈ Z, b ≠ 0}
Real Numbers:
R = Q ∪ Q′
Disjoint Sets:
Q ∩ Q′ = ∅
Circle Relations:
Circumference = 2πr
Diameter = 2r
Circumference / Diameter = π
Right-Angled Triangle:
OC = √(OA² + AC²)
If OA = 1 and AC = 1:
OC = √(1² + 1²) = √2
Closure Property:
a + b ∈ R
a × b ∈ R
Commutative Property:
a + b = b + a
ab = ba
Associative Property:
a + (b + c) = (a + b) + c
a(bc) = (ab)c
Identity Property:
a + 0 = a
a × 1 = a
Inverse Property:
a + (−a) = 0
a × (1/a) = 1, where a ≠ 0
Distributive Property:
a(b + c) = ab + ac
a(b − c) = ab − ac
Equality Properties:
Reflexive: x = x
Symmetric: x = y ⇔ y = x
Transitive: x = y and y = z ⇒ x = z
Addition Property of Equality:
If x = y, then x + z = y + z
Multiplication Property of Equality:
If x = y, then xz = yz
Cancellation Properties:
x + z = y + z ⇒ x = y
xz = yz ⇒ x = y, where z ≠ 0
Trichotomy Property:
For real numbers x and y, exactly one holds:
x < y, x = y, or x > y
Transitive Inequality:
If x < y and y < z, then x < z
Addition Property of Inequality:
x < y ⇒ x + z < y + z
x > y ⇒ x + z > y + z
Multiplication Property of Inequality:
If z > 0, x < y ⇒ xz < yz
If z < 0, x < y ⇒ xz > yz
Reciprocal Inequality:
For non-zero x and y of the same sign:
If 0 < x < y, then 1/x > 1/y
If x < y < 0, then 1/x > 1/y
Absolute Value:
|x| = distance of x from zero
Distance between a and b = |a − b|

2. CONCEPTS

Number System

Natural Numbers (N):
1, 2, 3, 4, ...
Whole Numbers (W):
0, 1, 2, 3, 4, ...
Integers (Z):
..., −3, −2, −1, 0, 1, 2, 3, ...
Rational Numbers (Q):
Numbers expressible as a/b, where a and b are integers and b ≠ 0.
Irrational Numbers (Q′):
Numbers whose decimal expansions are non-terminating and non-recurring.
Real Numbers (R):
All rational and irrational numbers together.

Decimal Representation

Terminating Decimal:
A decimal with a finite number of digits after the decimal point.
Recurring Decimal:
A decimal in which one digit or a group of digits repeats in the same order.
Non-Terminating, Non-Recurring Decimal:
A decimal that continues indefinitely without a repeating pattern.
Decimal Representation Fact:
Every rational number has a terminating or recurring decimal expansion.
Real Number Set Relationship:
Q and Q′ are disjoint and together form R.

Representation on Number Line

Rational Numbers:
Draw a straight line and mark zero. Mark equal unit intervals on both sides. Positive numbers lie to the right and negative numbers to the left. Divide an interval into equal parts to locate fractions.
Irrational Numbers:
Construct a right-angled triangle with perpendicular sides of one unit each. Its hypotenuse is √2. Using this length as a radius from zero, mark √2 on the number line.

Properties of Real Numbers

Closure:
The sum and product of real numbers are real numbers.
Commutative:
The order of numbers does not change their sum or product.
Associative:
Changing the grouping does not change the sum or product.
Identity:
Zero is the additive identity and one is the multiplicative identity.
Inverse:
The additive inverse of a is −a. The multiplicative inverse is 1/a for a ≠ 0.
Distributive:
Multiplication distributes over addition and subtraction.

Ordering and Inequalities

Ordering:
Real numbers can be compared using =, < and >.
Multiplying an Inequality:
Multiplication by a positive number preserves the inequality sign. Multiplication by a negative number reverses it.

Absolute Value

Meaning:
Absolute value is the distance of a number from zero on the number line.
Important Properties:
Absolute value is never negative. Opposite numbers have equal absolute values. The distance between two points is the absolute difference of their coordinates.

3. DEFINITIONS

Numbers:
Numbers are a useful language for counting, measuring, identifying and performing calculations.
Rational Number:
A number expressible as a/b, where a and b are integers and b is not zero.
Origin of the Word Rational:
The word rational comes from ratio, referring to the ratio of two integers.
Terminating Decimal Fraction:
A decimal fraction having a finite number of digits in its decimal part.
Recurring Decimal Fraction:
A decimal fraction in which a digit or group of digits repeats in the same order.
Irrational Number:
A real number whose decimal expansion is non-terminating and non-recurring.
Real Numbers:
Numbers represented on the continuous number line, including rational and irrational numbers.
Absolute Value / Modulus:
The non-negative distance of a number from zero, represented by vertical bars |x|.
Opposite Numbers:
Two numbers with equal absolute values but opposite signs.
Learning Outcomes:
Recognize and classify real numbers, distinguish rational and irrational numbers, represent numbers on a number line, identify decimal types, use real-number properties, compare numbers and understand absolute value.

4. KEY POINTS

Rational numbers can be written as a/b, where b ≠ 0.
Every integer is rational because it can be written as a fraction with denominator 1.
Terminating and recurring decimals are rational numbers.
Irrational decimals are non-terminating and non-recurring.
Real numbers consist of rational and irrational numbers: R = Q ∪ Q′.
Rational and irrational sets do not overlap: Q ∩ Q′ = ∅.
Zero is the additive identity. One is the multiplicative identity.
Zero has no multiplicative inverse.
The properties of closure, commutativity, associativity, identity, inverse and distributivity apply to real numbers where defined.
When multiplying an inequality by a negative number, reverse the inequality sign.
Absolute value represents distance, so it is always zero or positive.
The distance between two real numbers a and b is |a − b|.
