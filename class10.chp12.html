1. FORMULAS

Frequency Distribution

Cumulative Frequency: c.f. = f₁ + f₂ + ... + fₙ
Class Boundary: (Upper limit + Next lower limit) ÷ 2
Class Frequency: f = Current c.f. − Previous c.f.

Quartiles, Deciles and Percentiles

First Quartile: Q₁ = N/4 th value
Second Quartile: Q₂ = N/2 th value = Median
Third Quartile: Q₃ = 3N/4 th value
Decile: Dₖ = kN/10 th value
Percentile: Pₖ = kN/100 th value
Interquartile Range: IQR = Q₃ − Q₁
Lower Outlier Fence: Q₁ − 1.5(IQR)
Upper Outlier Fence: Q₃ + 1.5(IQR)

Range, Mean, Variance and Standard Deviation

Range: R = Maximum − Minimum
Mean for Grouped Data: x̄ = Σfx / Σf
Variance: S² = Σf(x − x̄)² / Σf
Direct Variance Formula:
S² = Σfx² / Σf − (Σfx / Σf)²
Standard Deviation: S = √[Σf(x − x̄)² / Σf]
Coefficient of Variation: CV = (SD / Mean) × 100%

Correlation and Line of Best Fit

Line of Best Fit: y = mx + c
Correlation Coefficient:
r = Σ[(xᵢ − x̄)(yᵢ − ȳ)] / √[Σ(xᵢ − x̄)² × Σ(yᵢ − ȳ)²]

Probability

Theoretical Probability:
P(A) = Favorable outcomes / Total equally likely outcomes
Experimental Probability:
P(A) = Number of times event occurs / Total trials
Complement Rule: P(A′) = 1 − P(A)
Addition Rule (Mutually Exclusive):
P(A ∪ B) = P(A) + P(B)
General Addition Rule:
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
Independent Events: P(A ∩ B) = P(A) × P(B)
Dependent Events: P(A ∩ B) = P(A) × P(B|A)
Conditional Probability:
P(A|B) = P(A ∩ B) / P(B), where P(B) > 0

2. CONCEPTS

Frequency Tables and Graphs

  • Frequency Polygon: Plot class midpoints against frequencies and join the points with straight lines.
  • Cumulative Frequency Polygon: Plot upper class boundaries against cumulative frequencies and join the points with straight lines.
  • Ogive: Draw a smooth cumulative frequency curve using class boundaries and cumulative frequencies.
  • To estimate quartiles from an ogive, locate N/4, N/2 and 3N/4 on the cumulative-frequency axis, then read the corresponding values on the horizontal axis.

Box-and-Whisker Plot

  • The box extends from Q₁ to Q₃.
  • The line inside the box represents the median (Q₂).
  • Whiskers extend towards the minimum and maximum non-outlier values.
  • Values outside the outlier fences may be plotted separately.

Scatter Diagram and Correlation

  • Positive Correlation: As x increases, y tends to increase.
  • Negative Correlation: As x increases, y tends to decrease.
  • No Correlation: No clear relationship appears between the variables.
  • A line of best fit shows the general trend of paired data.
  • Points closer to a straight-line pattern generally indicate stronger linear correlation.
  • Predictions outside the observed data range may be unreliable.

Comparing Data Sets

  • Calculate the mean and standard deviation for each data set.
  • Compare means to understand central tendency.
  • Compare standard deviations to understand spread.
  • Use coefficient of variation to compare relative spread when appropriate.

Probability Diagrams

  • Possibility Diagram: Lists or displays all possible combined outcomes.
  • Tree Diagram: Shows sequential events using branches and final outcomes.
  • Sample Space: All possible outcomes of an experiment.
  • Venn Diagram: Shows relationships between events, including intersections and unions.
  • For a tree diagram, multiply the probabilities along a path to find the probability of that sequence.

3. DEFINITIONS

Statistical Terms

Frequency Distribution: An arrangement of data showing how often each value or class occurs.
Cumulative Frequency: The running total of frequencies up to a specified class.
Quartiles: Values that divide ordered data into four parts.
Deciles: Values that divide ordered data into ten parts.
Percentiles: Values that divide ordered data into one hundred parts.
Interquartile Range (IQR): The difference between the third and first quartiles, representing the spread of the middle 50% of the data.
Range: The difference between the maximum and minimum values in a data set.
Variance: A measure of how far data values spread around their mean, based on squared deviations.
Standard Deviation: A measure of data spread around the mean, expressed in the same units as the data.
Coefficient of Variation: A percentage measure of relative dispersion, calculated by dividing standard deviation by mean and multiplying by 100.
Scatter Diagram: A graph that displays paired numerical observations as points.
Correlation: The direction and strength of association between two variables.
Line of Best Fit: A straight line that represents the overall trend of points in a scatter diagram.

Probability Terms

Experiment: A process or action that produces an outcome.
Outcome: A particular result of an experiment.
Sample Space: The set of all possible outcomes of an experiment.
Event: One or more outcomes of an experiment.
Possibility Diagram: A diagram that represents all possible outcomes of an experiment or combined events.
Tree Diagram: A diagram that shows the possible outcomes of sequential events using branches.
Independent Events: Events in which the occurrence of one does not affect the probability of the other.
Dependent Events: Events in which the occurrence of one affects the probability of the other.
Mutually Exclusive Events: Events that cannot occur at the same time.
Conditional Probability: The probability of an event occurring when another event is already known to have occurred.
Complement of an Event: The event that the original event does not occur.

4. KEY POINTS

  • N represents the total number of observations or total frequency.
  • Q₁ = P₂₅, Q₂ = P₅₀ = Median, and Q₃ = P₇₅.
  • D₁ = P₁₀, D₅ = P₅₀ = Q₂, and D₉ = P₉₀.
  • The interquartile range represents the middle 50% of the data.
  • Common outlier limits are Q₁ − 1.5(IQR) and Q₃ + 1.5(IQR).
  • A smaller standard deviation indicates less absolute spread around the mean.
  • A smaller coefficient of variation generally indicates greater consistency when comparing suitable data sets.
  • The correlation coefficient r lies between −1 and +1.
  • A positive r indicates positive linear association; a negative r indicates negative linear association.
  • A correlation close to zero indicates weak or no linear association, not necessarily no relationship of any kind.
  • Probability lies between 0 and 1, inclusive.
  • P(S) = 1 for the complete sample space.
  • P(∅) = 0 for an impossible event.
  • The probability of an event and its complement adds up to 1.
  • For mutually exclusive events, add their probabilities to find the probability that either occurs.
  • For independent events, multiply their probabilities to find the probability that both occur.
  • For dependent events, use conditional probability in the multiplication rule.
  • When a card is replaced before the next draw, the draws are independent under the same deck conditions.
  • When a card is not replaced, the second draw's probability may change.
  • In a tree diagram, multiply probabilities along a path. Add probabilities for mutually exclusive paths that lead to the required event.
Remember: Frequency graphs help describe distributions, while scatter diagrams help examine relationships between paired variables.
