Inverse Trigonometric Functions

← Back to Chapters

Definitions

Inverse Trigonometric Function: An inverse trigonometric function gives the angle corresponding to a given trigonometric value.
Principal Value: The unique angle selected from a specified interval for an inverse trigonometric function.
Principal Cosine Function: Cosine restricted to x ∈ [0, π], making it one-to-one.
Principal Sine Function: Sine restricted to x ∈ [−π/2, π/2], making it one-to-one.
Principal Tangent Function: Tangent restricted to x ∈ (−π/2, π/2), making it one-to-one.
Principal Cotangent Function: Cotangent restricted to x ∈ (0, π), making it one-to-one.
Principal Secant Function: Secant restricted to [0, π] except π/2.
Principal Cosecant Function: Cosecant restricted to [−π/2, π/2] except 0.
Graph of an Inverse Function: The graph of an inverse function is the reflection of the original restricted function in the line y = x.

1. Basic Inverse Trigonometric Functions

Arccos x = Cos⁻¹x
Arcsin x = Sin⁻¹x
Arctan x = Tan⁻¹x
Arcsec x = Sec⁻¹x
Arccsc x = Csc⁻¹x
Arccot x = Cot⁻¹x
Cos⁻¹(0.5) = π/3

2. Domain and Range

Function Domain Range Nature
Cos⁻¹x [−1, 1] [0, π] Decreasing, one-to-one
Sin⁻¹x [−1, 1] [−π/2, π/2] Increasing, odd, one-to-one
Tan⁻¹x R (−π/2, π/2) Increasing, odd, one-to-one
Cot⁻¹x R (0, π) Decreasing, one-to-one
Sec⁻¹x (−∞,−1] ∪ [1,∞) [0,π/2) ∪ (π/2,π] Non-periodic
Csc⁻¹x (−∞,−1] ∪ [1,∞) [−π/2,0) ∪ (0,π/2] Non-periodic, odd
Inverse graph = reflection of original graph in y = x

3. Inverse Cosine

y = Cos⁻¹x, x ∈ [−1,1], y ∈ [0,π]
Cos⁻¹(1) = 0
Cos⁻¹(0) = π/2
Cos⁻¹(−1) = π
Cos⁻¹(−1/2) = 2π/3
Cos(Cos⁻¹x) = x, x ∈ [−1,1]
Cos⁻¹(Cos x) = x, x ∈ [0,π]
Cos⁻¹(−x) = π − Cos⁻¹x
Cos⁻¹x = Sin⁻¹(√(1−x²)), x ∈ [0,1]
Cos⁻¹x = π − Sin⁻¹(√(1−x²)), x ∈ [−1,0]

4. Inverse Sine

y = Sin⁻¹x, x ∈ [−1,1], y ∈ [−π/2,π/2]
Sin⁻¹(−1) = −π/2
Sin⁻¹(0) = 0
Sin⁻¹(1) = π/2
Sin⁻¹(−1/√2) = −π/4
Sin(Sin⁻¹x) = x, x ∈ [−1,1]
Sin⁻¹(Sin x) = x, x ∈ [−π/2,π/2]
Sin⁻¹(−x) = −Sin⁻¹x

5. Inverse Tangent

y = Tan⁻¹x, x ∈ R, y ∈ (−π/2,π/2)
Tan⁻¹(0) = 0
Tan⁻¹(1) = π/4
Tan⁻¹(√3) = π/3
Tan⁻¹(−1/√3) = −π/6
Tan(Tan⁻¹x) = x
Tan⁻¹(Tan x) = x, x ∈ (−π/2,π/2)
Tan⁻¹(−x) = −Tan⁻¹x
Tan⁻¹x + Tan⁻¹(1/x) = π/2, x > 0
Tan⁻¹x + Tan⁻¹(1/x) = −π/2, x < 0

6. Inverse Cotangent

y = Cot⁻¹x, x ∈ R, y ∈ (0,π)
Cot⁻¹(1) = π/4
Cot⁻¹(0) = π/2
Cot⁻¹(−√3) = 2π/3
Cot(Cot⁻¹x) = x
Cot⁻¹(Cot x) = x, x ∈ (0,π)
Cot⁻¹(−x) = π − Cot⁻¹x
Cot⁻¹x = Tan⁻¹(1/x), x > 0
Cot⁻¹x = Tan⁻¹(1/x) + π, x < 0

7. Inverse Secant

y = Sec⁻¹x, x ∈ (−∞,−1] ∪ [1,∞)
Range = [0,π/2) ∪ (π/2,π]
Sec⁻¹(1) = 0
Sec⁻¹(−1) = π
Sec⁻¹(2/√3) = π/6
Sec⁻¹(−2) = 2π/3
Sec(Sec⁻¹x) = x
Sec⁻¹(Sec x) = x, x ∈ [0,π/2) ∪ (π/2,π]
Sec⁻¹(−x) = π − Sec⁻¹x
Sec⁻¹x = Cos⁻¹(1/x)

8. Inverse Cosecant

y = Csc⁻¹x, x ∈ (−∞,−1] ∪ [1,∞)
Range = [−π/2,0) ∪ (0,π/2]
Csc⁻¹(−1) = −π/2
Csc⁻¹(1) = π/2
Csc⁻¹(√2) = π/4
Csc⁻¹(−√2) = −π/4
Csc(Csc⁻¹x) = x
Csc⁻¹(Csc x) = x, x ∈ [−π/2,0) ∪ (0,π/2]
Csc⁻¹(−x) = −Csc⁻¹x
Csc⁻¹x = Sin⁻¹(1/x)

9. Important Properties

Sin⁻¹x + Cos⁻¹x = π/2
Tan⁻¹x + Cot⁻¹x = π/2
Sec⁻¹x + Csc⁻¹x = π/2
Sin⁻¹(1/x) = Csc⁻¹x
Cos⁻¹(1/x) = Sec⁻¹x
Tan⁻¹(1/x) = Cot⁻¹x, x > 0
Tan⁻¹(1/x) = −π + Cot⁻¹x, x < 0

10. Graphs of Inverse Trigonometric Functions

Cos⁻¹x: Domain [−1,1], Range [0,π], decreasing.
Sin⁻¹x: Domain [−1,1], Range [−π/2,π/2], increasing and odd.
Tan⁻¹x: Domain R, Range (−π/2,π/2), increasing.
Cot⁻¹x: Domain R, Range (0,π), decreasing.
Sec⁻¹x: Domain (−∞,−1] ∪ [1,∞), Range [0,π/2) ∪ (π/2,π].

10. Graphs of Inverse Trigonometric Functions

Cos⁻¹x: Domain [−1,1], Range [0,π], decreasing.
Sin⁻¹x: Domain [−1,1], Range [−π/2,π/2], increasing and odd.
Tan⁻¹x: Domain R, Range (−π/2,π/2), increasing.
Cot⁻¹x: Domain R, Range (0,π), decreasing.
Sec⁻¹x: Domain (−∞,−1] ∪ [1,∞), Range [0,π/2) ∪ (π/2,π].
Csc⁻¹x: Domain (−∞,−1] ∪ [1,∞), Range [−π/2,0) ∪ (0,π/2].
Tan⁻¹x asymptotes: y = ±π/2
Cot⁻¹x asymptotes: y = 0 and y = π
Sec⁻¹x asymptote: y = π/2
Csc⁻¹x asymptote: y = 0

11. Important Principal Values

Cos⁻¹(√3/2) = π/6
Sin⁻¹(1) = π/2
Tan⁻¹(√3) = π/3
Cot⁻¹(1/√3) = π/3
Sec⁻¹(2/√3) = π/6
Csc⁻¹(−√2) = −π/4
Cos⁻¹(−1/2) = 2π/3
Tan⁻¹(1/√3) = π/6
Csc⁻¹(−2) = −π/6

Key Points

• Inverse trigonometric functions are not reciprocals. Sin⁻¹x ≠ 1/Sin x.
• The principal interval makes the original function one-to-one.
• Domain and range are interchanged for a function and its inverse.
• The graph of an inverse function is reflected in y = x.
• Sin⁻¹x and Cos⁻¹x require x ∈ [−1,1].
• Tan⁻¹x and Cot⁻¹x accept every real number.
• Sec⁻¹x and Csc⁻¹x require x ∈ (−∞,−1] ∪ [1,∞).
• Always check the principal range when finding an inverse trigonometric value.
