Important Formulas

1. Velocity and Displacement

v = dS/dt
S = ∫v dt

2. Acceleration

a = dv/dt
a = d²S/dt²
v = ∫a dt

3. Displacement-Time Graph

Slope of d-t graph = Velocity
Slope = d/t

4. Velocity-Time Graph

Slope = (v₂ − v₁)/(t₂ − t₁) = Acceleration
Area under v-t graph = Displacement

5. Position Function

S(t) = displacement at time t
Displacement = S(t₂) − S(t₁)

6. Acceleration from Position

v(t) = dS/dt
a(t) = d²S/dt²

7. Upward Throw

a = −g
v = −gt + u
S = −½gt² + ut
At maximum height: v = 0
Time to maximum height = u/g
Maximum height = u²/(2g)
Total distance = u²/g

8. Vector-Valued Function

r(t) = x(t)î + y(t)ĵ + z(t)k̂
|r| = √(x² + y² + z²)
v(t) = r′(t)
a(t) = r″(t)
f′(t) = f₁′(t)î + f₂′(t)ĵ + f₃′(t)k̂

Definitions

  • Scalar: A physical quantity having magnitude only.
  • Vector: A physical quantity having both magnitude and direction.
  • Distance: The total path length travelled by an object.
  • Speed: The rate at which distance is covered with respect to time.
  • Displacement: The directed straight-line distance from initial position to final position.
  • Velocity: The rate of change of displacement with respect to time.
  • Acceleration: The rate of change of velocity with respect to time.
  • Instantaneous Velocity: Velocity at a particular instant of time.
  • Uniform Motion: Motion in which an object covers equal displacements in equal intervals of time.
  • Vector-Valued Function: A function whose output is a vector.
  • Scalar-Valued Function: A function whose output is a single real number.
  • Domain of Vector Function: The common set of values of t for which all component functions are defined.

Key Points

  • Distance, mass, time and speed are scalar quantities.
  • Displacement, velocity, acceleration and weight are vector quantities.
  • Distance depends on the total path travelled.
  • Displacement depends only on initial and final positions.
  • Speed has no direction, while velocity has direction.
  • In a displacement-time graph, the slope represents velocity.
  • Positive slope represents positive velocity.
  • Negative slope represents negative velocity.
  • A horizontal displacement-time graph means velocity is zero.
  • In a velocity-time graph, the slope represents acceleration.
  • A horizontal velocity-time graph represents constant velocity.
  • Positive slope of a v-t graph represents positive acceleration.
  • Negative slope represents negative acceleration or retardation.
  • The area under a velocity-time graph gives displacement.
  • To find velocity from a position function, differentiate the position function.
  • To find acceleration, differentiate velocity or take the second derivative of position.
  • To find displacement from velocity, integrate velocity with respect to time.
  • To find velocity from acceleration, integrate acceleration with respect to time.
  • For upward motion, gravity acts downward, so if upward is positive, a = −g.
  • At maximum height, the instantaneous velocity becomes zero.
  • For a vector-valued function, each component is differentiated separately.
  • The derivative of a vector-valued position function gives velocity.
  • The second derivative of a vector-valued position function gives acceleration.
  • The domain of a vector-valued function is the intersection of the domains of all its components.
