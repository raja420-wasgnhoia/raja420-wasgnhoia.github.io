FORMULAS & RULES

1. Linear Equation in One Variable

General form: ax + b = 0, where a and b are constants and a ≠ 0.
Example: 3x + 4 = 16 → 3x − 12 = 0.
5x + 3x = 7x + 9 → 8x = 7x + 9 → x = 9.
4x − 20 = 2x + 6 → 2x = 26 → x = 13.
Three consecutive odd numbers: x, x + 2, x + 4.
x + (x + 2) + (x + 4) = 57 → x = 17.
Numbers: 17, 19, 21.
x + 3.8 = 2.3 → x = 2.3 − 3.8 = −1.5.
x/3 = 27 → x = 27 × 3 = 81.

2. Literal Equations

General literal equation: ax + b = c.
ax + b = c → ax = c − b → x = (c − b)/a, where a ≠ 0.
For 2x + 5 = 11: x = (11 − 5)/2 = 3.
3x + 2y = 8 → 2y = 8 − 3x → y = (8 − 3x)/2 = 4 − 3x/2.
Area of triangle: A = ½bh.
Solving for height: 2A = bh → h = 2A/b, where b ≠ 0.
Balance rule: Whatever operation is performed on one side of an equation must also be performed on the other side.

3. Linear Equations in Two Variables

General form: ax + by = c, where a, b, c are constants and a and b are not both zero.
A solution is an ordered pair (x, y) that makes the equation true.
2x + 3y = 50.
If x = 7: 14 + 3y = 50 → y = 12. Solution: (7, 12).
If x = 10: 20 + 3y = 50 → y = 10. Solution: (10, 10).
x + y = 5 → positive integer solutions: (1,4), (2,3), (3,2), (4,1).
2y = 4x + 6 → 4x − 2y = −6.
For x = 10: y = 23. Ordered pair: (10, 23).
For y − x = −3, (8, 11) is not a solution because 11 − 8 = 3 ≠ −3.
For 3x − y = 7: (3,4) is not a solution; (1,−4) is a solution.

4. Graphs of Linear Equations

For y = 2x − 1: (−2,−5), (−1,−3), (0,−1), (1,1), (2,3).
For −2x + y = 3: y = 2x + 3.
For y = 2x + 3: (−4,−5), (−3,−3), (−2,−1), (−1,1), (0,3), (1,5).
The graph of a linear equation in two variables is a straight line.
If b = 0 in ax + by = c, then ax = c → x = c/a, where a ≠ 0. This is a vertical line.
Horizontal line: y = c.
Vertical line: x = c.
For y = −4: (−3,−4), (−1,−4), (0,−4).
For x = 6: (6,−1), (6,0), (6,1).
For y = mx, the line passes through the origin (0,0).
Examples: y = 4x has slope m = 4; y = −3x has slope m = −3.

5. Simultaneous Equations

2x − y = 8 ...(i); 2x + y = 4 ...(ii).
Common solution: (3, −2).

6. Elimination Method

Example: 2x + y = 8 ...(i); x + 2y = 10 ...(ii).
Multiply (ii) by 2: 2x + 4y = 20 ...(iii).
Subtract (iii) from (i): −3y = −12 → y = 4.
Substitute y = 4: 2x + 4 = 8 → x = 2.
Solution: (x, y) = (2, 4).
Example: −2x + y = −3 ...(i); 4x + 5y = 7 ...(ii).
Multiply (i) by 2: −4x + 2y = −6 ...(iii).
Add (ii) and (iii): 7y = 1 → y = 1/7.
Substitute in (i): −2x + 1/7 = −3 → x = 11/7.
Solution: (x, y) = (11/7, 1/7).
Example: 5x − 4y = 10 ...(i); 2x + 8y = 4 ...(ii).
Multiply (i) by 2: 10x − 8y = 20 ...(iii).
Multiply (ii) by 5: 10x + 40y = 20 ...(iv).
Subtract (iv) from (iii): −48y = 0 → y = 0.
Substitute in (i): 5x = 10 → x = 2.
Solution: (x, y) = (2, 0).

7. Substitution Method

Example: x + 4y = 2 ...(i); 5x − 4y = 10 ...(ii).
From (i): x = 2 − 4y ...(iii).
Substitute in (ii): 5(2 − 4y) − 4y = 10.
10 − 20y − 4y = 10 → −24y = 0 → y = 0.
x = 2 − 4(0) = 2.
Solution: (x, y) = (2, 0).

CONCEPTS

1. Algebra and Equations

Algebra uses letters to represent unknown numbers and helps solve real-world problems. A word problem can be translated into a mathematical equation by identifying the unknown and expressing the given relationship.

2. Word Problem to Equation

Example: Five times a number plus three times the same number equals seven times the number plus nine.

Let the number be x.

5x + 3x = 7x + 9

8x = 7x + 9

8x − 7x = 9

x = 9

3. Linear Equation in One Variable

A linear equation in one variable has the general form ax + b = 0, where a and b are constants and a ≠ 0. Examples include 3x − 6 = 0, 7y = 14, and 9z = 27.

4. Algebraic Sentences

An algebraic sentence combines an algebraic expression with a relation such as =, >, <, ≤, ≥, or ≠.

  • Open sentence: Its truth is not known until the variable is replaced with a value.
  • Closed sentence: Its truth or falsity is already known.
  • Equation: An algebraic sentence stating that two expressions are equal.

Examples: y + 8 = 15, 8p − 2 = 3, 3x + 5 = 11, and 9z − 8 = 19.

5. Solving a Linear Equation

To solve an equation means to find the value of the variable that makes the equation true. Keep both sides balanced by performing the same operation on both sides.

Example: 4x − 20 = 2x + 6

4x − 2x = 6 + 20

2x = 26

x = 13

6. Consecutive Odd Numbers

Three consecutive odd numbers differ by 2. Let the smallest be x. The numbers are x, x + 2, and x + 4.

x + (x + 2) + (x + 4) = 57

3x + 6 = 57 → 3x = 51 → x = 17.

The numbers are 17, 19, and 21.

7. Correcting Common Errors

x + 3.8 = 2.3 gives x = −1.5, not 6.1.

x/3 = 27 gives x = 81, not 9.

8. Literal Equations

A literal equation uses letters to represent constants and coefficients. For example, ax + b = c has the same general form as 2x + 5 = 11.

Rearrange ax + b = c to make x the subject:

ax = c − b

x = (c − b)/a, where a ≠ 0.

If a = 2, b = 5, and c = 11, then x = 3.

9. Formula for the Area of a Triangle

The area of a triangle is A = ½bh, where b is the base and h is the height.

To make h the subject:

2A = bh

h = 2A/b

For A = 64.6 m² and b = 14 m, h = 129.2/14 ≈ 9.23 m.

10. Linear Equation in Two Variables

A linear equation in two variables has the general form ax + by = c, where a, b, and c are constants and a and b are not both zero.

A solution is an ordered pair (x, y) that makes the equation true. A linear equation in two variables can have infinitely many solutions.

Price example: Two sharpeners and three pens cost 50 rupees.

Let x be the price of one sharpener and y the price of one pen.

2x + 3y = 50.

If x = 7, then y = 12, giving (7, 12). If x = 10, then y = 10, giving (10, 10).

Sum example: Two positive integers have a sum of 5.

x + y = 5.

Possible ordered pairs are (1, 4), (2, 3), (3, 2), and (4, 1).

Age example: Twice the father's age equals four times the son's age plus six.

Let the father's age be y and the son's age be x.

2y = 4x + 6 → 4x − 2y = −6.

If x = 10, then y = 23. The ordered pair (10, 23) satisfies the equation.

11. Checking Ordered Pairs

To check whether an ordered pair is a solution, substitute its x- and y-values into the equation.

For y − x = −3, the pair (8, 11) is not a solution because 11 − 8 = 3, not −3.

For 3x − y = 7:

  • (3, 4): 3(3) − 4 = 5, so it is not a solution.
  • (1, −4): 3(1) − (−4) = 7, so it is a solution.

12. Graphing Linear Equations

Find several ordered pairs that satisfy the equation, plot them on the Cartesian plane, and join them. The graph of a linear equation in two variables is a straight line.

Example: y = 2x − 1

  • x = −2 gives y = −5.
  • x = −1 gives y = −3.
  • x = 0 gives y = −1.
  • x = 1 gives y = 1.
  • x = 2 gives y = 3.

Ordered pairs: (−2, −5), (−1, −3), (0, −1), (1, 1), (2, 3).

Example: y = 2x + 3

Ordered pairs: (−4, −5), (−3, −3), (−2, −1), (−1, 1), (0, 3), (1, 5).

13. Horizontal and Vertical Lines

Horizontal line y = c: Every point has the same y-coordinate. It is parallel to the x-axis.

For y = −4, points include (−3, −4), (−1, −4), and (0, −4). The y-intercept is −4. If c ≠ 0, the line has no x-intercept.

Vertical line x = c: Every point has the same x-coordinate. It is parallel to the y-axis.

For x = 6, points include (6, −1), (6, 0), and (6, 1). The x-intercept is (6, 0). If c ≠ 0, the line has no y-intercept.

Graph of x = c: If b = 0 in ax + by = c, then ax = c and x = c/a, where a ≠ 0. Examples include x = 2 and x = −7.

14. Graph of y = mx

In y = mx, m is the slope. The line passes through the origin (0, 0). Examples include y = 4x and y = −3x.

15. Simultaneous Linear Equations

Two or more linear equations that must be solved together are called simultaneous linear equations or a system of linear equations.

The solution is an ordered pair that satisfies every equation in the system.

Example: 2x − y = 8 and 2x + y = 4 have the common solution (3, −2).

Check: 2(3) − (−2) = 8 and 2(3) + (−2) = 4.

16. Elimination Method

The elimination method removes one variable by adding or subtracting equations after making the coefficients of that variable equal.

  1. Write the two equations.
  2. Multiply one or both equations by suitable numbers to make coefficients equal.
  3. Add or subtract the equations to eliminate a variable.
  4. Solve for the remaining variable.
  5. Substitute its value into either original equation to find the other variable.

Example 1: 2x + y = 8 and x + 2y = 10.

Multiply the second equation by 2: 2x + 4y = 20.

Subtract: −3y = −12, so y = 4.

Substitute: 2x + 4 = 8, so x = 2.

Example 2: −2x + y = −3 and 4x + 5y = 7.

Double the first equation: −4x + 2y = −6.

Add the equations: 7y = 1, so y = 1/7.

Then −2x + 1/7 = −3, so x = 11/7.

Example 3: 5x − 4y = 10 and 2x + 8y = 4.

Multiply the first equation by 2 and the second by 5:

10x − 8y = 20 and 10x + 40y = 20.

Subtract: −48y = 0, so y = 0.

Then 5x = 10, so x = 2.

17. Substitution Method

The substitution method expresses one variable in terms of the other and substitutes that expression into the second equation.

  1. Write both equations.
  2. Make one variable the subject of either equation.
  3. Substitute that expression into the other equation.
  4. Solve the resulting equation.
  5. Substitute the value found to determine the other variable.

Example: x + 4y = 2 and 5x − 4y = 10.

From the first equation: x = 2 − 4y.

Substitute into the second: 5(2 − 4y) − 4y = 10.

10 − 20y − 4y = 10 → −24y = 0 → y = 0.

x = 2 − 4(0) = 2.

Solution: (x, y) = (2, 0).

DEFINITIONS

Algebra: A branch of mathematics that uses letters and symbols to represent numbers and relationships.

Linear equation in one variable: An equation of the form ax + b = 0, where a ≠ 0.

Algebraic sentence: A mathematical statement containing algebraic expressions and a relation.

Open sentence: A statement whose truth depends on the value of its variable.

Closed sentence: A statement that is known to be true or false.

Equation: A mathematical statement showing that two expressions are equal.

Solution of an equation: A value of the variable that makes the equation true.

Literal equation: An equation in which letters represent constants, coefficients, or variables.

Linear equation in two variables: An equation of the form ax + by = c, where a and b are not both zero.

Ordered pair: A pair (x, y) that represents a point and can be a solution of an equation.

Solution set: The set of all values or ordered pairs that satisfy an equation.

Graph of a linear equation: A straight line representing all ordered pairs that satisfy the equation.

Horizontal line: A line parallel to the x-axis, described by y = c.

Vertical line: A line parallel to the y-axis, described by x = c.

Slope: A measure of a line's steepness. In y = mx, m is the slope.

Simultaneous linear equations: Two or more equations solved together to find a common solution.

Elimination method: A method of solving simultaneous equations by eliminating one variable through addition or subtraction.

Substitution method: A method of solving simultaneous equations by substituting an expression for one variable into another equation.

KEY POINTS

  • Translate word problems into equations by defining the unknown variable first.
  • Keep an equation balanced by doing the same operation on both sides.
  • For ax + b = c, x = (c − b)/a, provided a ≠ 0.
  • Consecutive odd numbers differ by 2.
  • The area of a triangle is A = ½bh.
  • A solution of an equation in two variables is an ordered pair (x, y).
  • A linear equation in two variables may have infinitely many solutions.
  • Substitute an ordered pair into the equation to check whether it is a solution.
  • The graph of a linear equation in two variables is a straight line.
  • Horizontal lines have constant y-coordinates and are parallel to the x-axis.
  • Vertical lines have constant x-coordinates and are parallel to the y-axis.
  • The line y = mx passes through the origin.
  • A solution of simultaneous equations must satisfy all equations in the system.
  • In elimination, make coefficients equal before adding or subtracting equations.
  • In substitution, express one variable in terms of the other and substitute it.
  • Always check the final values in the original equations.
