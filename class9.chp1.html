1. FORMULAS

1.1 Properties of Real Numbers

Closure Property
a + b ∈ R,   ab ∈ R
Commutative Property
a + b = b + a
ab = ba
Associative Property
a + (b + c) = (a + b) + c
a(bc) = (ab)c
Additive Identity
a + 0 = a
Multiplicative Identity
a × 1 = a
Additive Inverse
a + (−a) = 0
Multiplicative Inverse
a × (1/a) = 1,   a ≠ 0
Distributive Property
a(b + c) = ab + ac
a(b − c) = ab − ac
Real Numbers
R = Q ∪ Q′
Q ∩ Q′ = ∅

1.2 Properties of Equality

Reflexive Property
a = a
Symmetric Property
If a = b, then b = a
Transitive Property
If a = b and b = c, then a = c
Additive Property
If a = b, then a + c = b + c
Multiplicative Property
If a = b, then ac = bc
Cancellation Laws
If a + c = b + c, then a = b
If ac = bc and c ≠ 0, then a = b

1.3 Properties of Inequality

Trichotomy Property
Exactly one is true: a < b, a = b, or a > b
Transitive Property
If a < b and b < c, then a < c
Addition Rule
If a < b, then a + c < b + c
Multiplication by a Positive Number
If a < b and c > 0, then ac < bc
Multiplication by a Negative Number
If a < b and c < 0, then ac > bc
Inequality Cancellation
If a + c < b + c, then a < b
If ac < bc and c > 0, then a < b
If ac < bc and c < 0, then a > b

1.4 Radicals

Square Root
(√a)² = a, for a ≥ 0
√(a²) = |a|
nth Root
If aⁿ = b, then a = b1/n = ⁿ√b
Square Root Notation
√b = ²√b
Product Rule for Radicals
ⁿ√a × ⁿ√b = ⁿ√(ab)
Quotient Rule for Radicals
ⁿ√a / ⁿ√b = ⁿ√(a/b), where b ≠ 0
Reducing the Index
ⁿ√(aᵐ) = am/n
Reduce m/n to its lowest terms to simplify the index.

1.5 Laws of Exponents

Rational Exponent
b1/n = ⁿ√b
Fractional Exponent
bm/n = (ⁿ√b)ᵐ = ⁿ√(bᵐ)
Negative Exponent
a−n = 1/aⁿ, where a ≠ 0
b−m/n = 1/bm/n, where defined
Product Rule
aᵐ × aⁿ = am+n
Quotient Rule
aᵐ / aⁿ = am−n, where a ≠ 0
Power of a Power
(aᵐ)ⁿ = amn
Power of a Product
(ab)ⁿ = aⁿbⁿ
Power of a Quotient
(a/b)ⁿ = aⁿ/bⁿ, where b ≠ 0
Negative Power of a Quotient
(a/b)−n = (b/a)ⁿ, where a ≠ 0 and b ≠ 0

1.6 Percentage and Practical Applications

Percentage
Percentage = (Part / Whole) × 100%
Finding a Percentage of a Quantity
Part = (Percentage / 100) × Whole
Remaining Balance
Remaining Balance = Original Balance − Total Amount Spent
Average Speed
Speed = Distance / Time
Distance = Speed × Time
Time = Distance / Speed
Unit Rate
Cost per unit = Total Cost / Number of Units

2. CONCEPTS

Number Systems

Natural Numbers (N): 1, 2, 3, 4, ...
Whole Numbers (W): 0, 1, 2, 3, ...
Integers (Z): ..., −3, −2, −1, 0, 1, 2, 3, ...
Rational Numbers (Q): Numbers expressible as p/q, where p and q are integers and q ≠ 0.
Irrational Numbers (Q′): Real numbers that cannot be expressed as a ratio of two integers.
Relationship:
N ⊂ W ⊂ Z ⊂ Q ⊂ R
Irrational numbers are also real numbers, but they are not rational numbers.

Real Number Line

  • Zero is called the origin.
  • Positive numbers lie to the right of zero.
  • Negative numbers lie to the left of zero.
  • Every real number corresponds to a point on the number line.
  • Terminating decimals include numbers such as 7/8 = 0.875.
  • Recurring decimals include numbers such as 1/3 = 0.333...
  • Irrational numbers have non-terminating, non-recurring decimal expansions.

Graphing Inequalities

Filled circle: The endpoint is included (≤ or ≥).
Hollow circle: The endpoint is excluded (< or >).
Arrow to the right: Numbers greater than the endpoint.
Arrow to the left: Numbers less than the endpoint.
  • x ≤ 2: all real numbers less than or equal to 2.
  • −6 < x < 4: all real numbers between −6 and 4, excluding both endpoints.
  • x > −4: all real numbers greater than −4.
  • −2 ≤ x < 1: includes −2 but excludes 1.

Radicals and Indices

  • In aⁿ, a is the base and n is the exponent.
  • In ⁿ√b, n is the index and b is the radicand.
  • The radical symbol is √.
  • The product and quotient rules for radicals require the same index.
  • For positive b, b1/n represents the principal nth root.
  • For even indices, real roots require a non-negative radicand.
  • For odd indices, negative radicands can have real roots.
  • When simplifying fractional exponents, reduce the exponent fraction where possible.

Practical Applications

  • Calculate a percentage by dividing the part by the whole and multiplying by 100.
  • For replenishment questions, divide the quantity that must be replaced by the amount removed each day.
  • For money balances, subtract all payments from the original balance.
  • For average speed, divide distance by time.

3. DEFINITIONS

Number

A number is an abstract idea used for counting and measuring. A numeral is a symbol used to represent a number.

Real Numbers

Real numbers consist of both rational and irrational numbers.

Rational Numbers

A rational number is any number that can be written as p/q, where p and q are integers and q ≠ 0.

Irrational Numbers

An irrational number is a real number that cannot be expressed as a ratio of two integers.

Equality

A mathematical statement that uses the equality symbol (=) is called an equality.

Inequality

A mathematical statement that compares quantities using symbols such as < or > is called an inequality.

Trichotomy Property

For any two real numbers a and b, exactly one of these statements is true: a < b, a = b, or a > b.

Graph of Real Numbers

The representation of real numbers on a number line is called graphing the real numbers or the graph of real numbers.

Square Root

A square root of a number n is a number m whose square is n. Every positive real number has two real square roots, which are additive inverses of each other.

Principal Square Root

The non-negative square root of a non-negative number is called its principal square root.

Radical

An expression containing a radical sign, such as √25, is called a radical expression.

Radical Sign

The symbol √ used to indicate a root is called the radical sign.

Radicand

The number or expression written under the radical sign is called the radicand.

nth Root

If aⁿ = b, then a is an nth root of b.

Base and Exponent

In an exponential expression aⁿ, a is the base and n is the exponent. The exponent indicates the power to which the base is raised.

Rational Exponent

An exponent written as a fraction, such as m/n, is called a rational exponent. It can be expressed using radicals when defined.

4. KEY POINTS

  • Zero is its own additive inverse.
  • Zero has no multiplicative inverse.
  • The multiplicative inverse of a non-zero number a is 1/a.
  • Real numbers are the union of rational and irrational numbers.
  • Rational and irrational numbers have no common elements.
  • When multiplying or dividing an inequality by a negative number, reverse the inequality sign.
  • When multiplying or dividing an inequality by a positive number, keep the inequality sign unchanged.
  • For an even index, the principal real root is non-negative.
  • There is no real square root of a negative number.
  • √a × √b = √(ab) when the real roots are defined.
  • Radical product and quotient rules require matching indices.
  • The denominator of a rational exponent gives the radical index.
  • The numerator of a rational exponent gives the power of the radical.
  • A negative exponent means taking the reciprocal, provided the base is non-zero.
  • In a number-line graph, filled endpoints are included and hollow endpoints are excluded.
  • Use consistent units when calculating speed, time, distance, or unit cost.
Remember: The principal square root of 25 is √25 = 5, but the equation x² = 25 has two solutions: x = 5 and x = −5.
Important restriction: Exponent and radical rules apply only when the expressions involved are defined. For example, division by zero is not allowed.
