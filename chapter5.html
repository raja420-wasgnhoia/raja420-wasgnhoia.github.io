Formulas

Dividend = Divisor × Quotient + Remainder
p(x) = (x − c)q(x) + r
where r = p(c)

📌 Key Points

• Exponent of the variable must be a whole number for a polynomial.

• P(x)/Q(x) is rational only if Q(x) ≠ 0.

• Every factor is a divisor, but every divisor is not a factor.

• Remainder = p(c) when divided by x − c.

• If p(c) = 0, then x − c is a factor.
