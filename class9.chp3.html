1. FORMULAS

Union of Sets

A ∪ B = {x | x ∈ A or x ∈ B}

Intersection of Sets

A ∩ B = {x | x ∈ A and x ∈ B}

Difference of Sets

A − B = {x | x ∈ A and x ∉ B}

Complement of a Set

A′ = U − A

2. CONCEPTS

Union: Elements belonging to either set or both sets.

Intersection: Elements common to both sets.

Difference: Elements in A that are not in B.

Complement: Elements of the universal set that are not in A.

3. DEFINITIONS

Set: A well-defined collection of distinct objects.

Subset: A set whose every element belongs to another set.

Universal Set: A set containing all elements under consideration.

Venn Diagram: A diagram used to represent sets and their relationships.

4. KEY POINTS

  • A ∪ B represents union.
  • A ∩ B represents intersection.
  • A′ represents complement.
  • Disjoint sets have no common elements.
  • The order of an ordered pair matters.
