CONCEPTS

1. Set: A collection of well-defined and distinct objects. Sets are important building blocks in mathematics.

2. Well-Defined Collection: A collection whose elements can be identified clearly from its description.

3. Distinct Objects: Objects in a set must be different. Elements cannot be repeated, and their order does not matter.

4. Representation of Sets: Sets are usually represented by capital letters such as A, B and C. Their elements may be numbers, symbols or objects.

5. Methods of Specifying a Set:

  • Description Method: Describe the elements in words.
  • Roster Method: List the elements inside curly brackets { }.

6. Ellipsis (...): Three dots indicate that a pattern continues. They are useful when listing every element is not practical.

7. Venn Diagram: A geometrical representation of sets. A rectangle commonly represents the universal set, while circles represent sets inside it. An overlapping region shows common elements.

8. Finite Set: A set whose elements can be listed and the listing eventually stops.

9. Infinite Set: A set whose elements continue without end. For example, {1, 2, 3, ...}.

10. Empty Set: A set with no elements. For example, the set of natural numbers less than 1, using the convention that natural numbers start at 1.

11. Singleton Set: A set containing exactly one element. For example, the set of natural numbers between 5 and 7 is {6}.

12. Universal Set: The largest set of all elements being considered in a particular situation. It is denoted by U.

13. Subset: A set A is a subset of B if every element of A is also in B.

14. Superset: If A ⊆ B, then B is a superset of A.

15. Proper Subset: A is a proper subset of B if every element of A belongs to B and B has at least one additional element.

16. Improper Subset: A set is an improper subset of itself. The two sets contain exactly the same elements, even if their order differs.

DEFINITIONS

Set: A set is a well-defined collection of distinct objects.

Element: Each object or member of a set is called an element.

Well-Defined Set: A set whose elements can be identified clearly without ambiguity.

Roster Form: A method of specifying a set by listing its elements inside curly brackets.

Venn Diagram: A geometrical representation of sets using closed curves, usually circles, inside a rectangle for the universal set.

Finite Set: A set containing a limited number of elements.

Infinite Set: A set containing infinitely many elements.

Empty or Null Set: A set that contains no elements, denoted by ∅ or { }.

Singleton Set: A set containing exactly one element.

Universal Set: The set containing all elements under consideration in a particular situation.

Subset: Set A is a subset of set B if every element of A is also an element of B.

Superset: If A is a subset of B, then B is called a superset of A.

Proper Subset: A is a proper subset of B if A ⊆ B and A ≠ B.

Improper Subset: A subset that is equal to the original set in terms of its elements.

KEY POINTS

  • Sets are usually named using capital letters.
  • The symbol ∈ means “is an element of”.
  • The symbol ∉ means “is not an element of”.
  • Elements of a set are distinct and are not repeated.
  • The order of elements in a set does not matter.
  • Use curly brackets { } to list the elements of a set.
  • The symbol ... shows that a pattern continues.
  • n(A) represents the number of elements in a finite set A.
  • The empty set is denoted by ∅ or { }.
  • The set {∅} is not empty. It contains one element: the empty set.
  • The set of whole numbers less than 1 is {0}, a singleton set.
  • The set of natural numbers less than 1 is empty when natural numbers start at 1.
  • Every set is a subset of itself: A ⊆ A.
  • The empty set is a subset of every set: ∅ ⊆ A.
  • If A ⊆ B, then B ⊇ A.
  • A proper subset has fewer elements than its superset.
  • A set is an improper subset of itself.
  • The rectangle in a Venn diagram usually represents U.
  • The overlapping area of two circles represents elements common to both sets.
