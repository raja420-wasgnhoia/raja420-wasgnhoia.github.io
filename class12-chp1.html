Key Points

  • Domain is the set of all allowed input values.
  • Range is the set of actual output values.
  • A function assigns each element of the domain exactly one element of the codomain.
  • A function is one-to-one when different inputs have different outputs.
  • A function is onto when every element of the codomain has a preimage.
  • A function is bijective when it is both one-to-one and onto.
  • A bijective function has an inverse function from its codomain to its domain.
  • The graph of a function and its inverse are reflections in the line y = x.
  • For a quadratic function, a determines the opening direction and affects its width.
  • The axis of symmetry of a quadratic function is x = −b/(2a).
  • The modulus function y = |x| has a V-shaped graph.
  • A polynomial has only non-negative integer powers of x.
  • In a rational function, the denominator cannot be zero.
  • For y = aˣ, the domain is R and the range is (0,∞).
  • For y = logₐx, x must be positive.
  • If a > 1, the exponential function represents growth.
  • If 0 < a < 1, the exponential function represents decay.
  • The graph of y = logₐx has a vertical asymptote at x = 0.
  • The horizontal line test can be used to check whether a function is one-to-one.
  • Graph transformations include translations, reflections, stretches and compressions.
  • For y = cf(x), |c| > 1 gives vertical stretching.
  • For y = cf(x), 0 < |c| < 1 gives vertical compression.
  • For y = f(cx), |c| > 1 gives horizontal compression.
  • For y = f(cx), 0 < |c| < 1 gives horizontal stretching.
  • Trigonometric functions have different domains and ranges.
  • Inverse trigonometric functions use restricted principal ranges so that they remain functions.
