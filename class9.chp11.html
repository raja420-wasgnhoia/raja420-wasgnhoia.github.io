1. FORMULAS

Class Boundaries

Adjustment Factor = ½ × (Lower Limit of a Class − Upper Limit of the Preceding Class)
Lower Boundary = Lower Class Limit − Adjustment Factor
Upper Boundary = Upper Class Limit + Adjustment Factor

Size of Class Interval

h = (xₗ − xₛ) / n
h = Size of Class Interval
xₗ = Largest Value
xₛ = Smallest Value
n = Approximate Number of Classes

Class Marks / Mid Values

Class Mark (x) = (Lower Class Limit + Upper Class Limit) / 2
Class Mark (x) = (Lower Class Boundary + Upper Class Boundary) / 2
Difference Between Consecutive Class Marks = h
Lower Boundary = Class Mark − h/2
Upper Boundary = Class Mark + h/2

Frequency and Cumulative Frequency

Total Frequency: n = Σf
Cumulative Frequency = Frequency of Current Class + Sum of All Preceding Frequencies

Histogram with Unequal Class Intervals

Area of Rectangle ∝ Frequency
Height × Width ∝ Frequency
Frequency Density (F.D.) = Frequency / Width of Class Interval
Height of Rectangle = Frequency Density
X-axis = Class Boundaries
Y-axis = Frequency Density

Frequency Polygon

New Class Marks = Existing Class Marks ± h
Extra Classes at Both Ends: Frequency = 0

Arithmetic Mean

Ungrouped Data
x̄ = Σx / n
Arithmetic Mean = Sum of Values / Number of Values
Grouped or Discrete Frequency Data
n = Σf
Σfx = Sum of (Frequency × Value)
x̄ = Σfx / Σf = Σfx / n
For Class Intervals Greater Than 1, Use Class Marks as x in the Mean Formula.

Median

Ungrouped Data
First arrange the data in ascending or descending order.
If n is Odd:
Median = Value at Position (n + 1) / 2
If n is Even:
Median = ½ × [Value at Position n/2 + Value at Position (n/2) + 1]
Symbol of Median = x̃ (x tilde)
Grouped Data
Median Position = n/2
n = Σf
Median = l + (h/f)(n/2 − c)
l = Lower Boundary of Median Class
h = Size of Class Interval
f = Frequency of Median Class
c = Cumulative Frequency of the Class Before the Median Class
n = Total Frequency

Mode

Ungrouped Data
Mode = Most Frequently Occurring Value
Grouped Data
Mode = l + [(fₘ − f₁) / (2fₘ − f₁ − f₂)] × h
l = Lower Boundary of Modal Class
fₘ = Frequency of Modal Class
f₁ = Frequency of Preceding Class
f₂ = Frequency of Following Class
h = Size of Class Interval
If the First Class Is Modal: f₁ = 0
If the Last Class Is Modal: f₂ = 0

Median of Discrete Frequency Distribution

Total Frequency: n = Σf
Median Position = n/2
Use Cumulative Frequency to Locate the Median.

Weighted Mean

Weighted Mean: x̄w = Σwx / Σw
x = Values of Data
w = Corresponding Weights
Σwx = Sum of Products of Weights and Values
Σw = Sum of Weights

Probability of a Single Event

P(E) = Number of Favourable Outcomes / Total Number of Equally Likely Outcomes
0 ≤ P(E) ≤ 1
Impossible Event: P(E) = 0
Equally Likely Outcomes in a Two-Outcome Experiment: P(E) = 1/2
Certain Event: P(E) = 1

Complementary Events

P(E′) = 1 − P(E)
P(E) + P(E′) = 1

Relative Frequency

Relative Frequency = Frequency of Event / Total Number of Trials
Relative Frequency is Also Called Experimental Probability or Empirical Probability.

Expected Frequency

Expected Frequency = Number of Trials × Probability of Event
Expected Frequency = n × p

2. CONCEPTS

Frequency Distribution

Raw / Ungrouped Data:
Data that has not been arranged in a systematic order.
Grouped Data:
Data arranged into classes, with the number of observations in each class recorded as its frequency.
Number of Groups:
The number of groups depends on the size of the data. It is commonly between 5 and 15, but there is no fixed rule.
Class Limits:
Each class has a lower class limit and an upper class limit. Both limits are included in the class.
Class Boundaries:
Boundaries remove gaps between consecutive classes and allow continuous data values to be represented correctly.
Size of Class Interval:
The difference between the lower limits or upper limits of two consecutive classes. It is denoted by h.
Class Mark:
The midpoint of a class, calculated by taking the average of its lower and upper limits or boundaries.
Frequency:
The number of times a value occurs or the number of observations in a class.
Cumulative Frequency:
The running total of frequencies up to and including a particular class.

Constructing a Frequency Distribution Table

Tally Bar Method
1. Decide the number of classes.
2. Calculate the approximate class interval size.
3. Write class limits in the first column.
4. Record each observation using a tally mark in its class.
5. Count the tally marks to obtain each frequency.
6. Add the frequencies and check that their total equals the number of observations.
Direct Observation Method
Write each observation in the appropriate class instead of using tally marks. The remaining steps are similar to the tally bar method.
Discrete Frequency Distribution:
A frequency distribution in which individual, separate values are recorded with their frequencies. Class boundaries are not needed when individual values are listed separately.

Graphs

Histogram:
A graph made of adjacent rectangles whose bases represent class intervals and whose areas are proportional to class frequencies.
For Equal Class Intervals, Rectangle Heights Are Proportional to Frequencies.
For Unequal Class Intervals, Use Frequency Density as the Rectangle Height so that rectangle areas remain proportional to frequencies.
Frequency Polygon:
Plot class marks on the horizontal axis and frequencies on the vertical axis. Join the plotted points using straight line segments and add zero-frequency points at both ends to close the polygon.
A Frequency Polygon Can Also Be Drawn by Joining the Midpoints of the Top Edges of Histogram Rectangles.

Averages

Arithmetic Mean:
The ratio of the sum of all values to the total number of values.
For grouped data, frequencies are used to calculate the total of the values. The total frequency gives the number of observations.
Median:
The middle value of data arranged in ascending or descending order.
For an odd number of observations, the median is the single middle value. For an even number, it is the arithmetic mean of the two middle values.
For grouped data, cumulative frequencies are used to locate the median class.
Mode:
The value that occurs most frequently in a data set.
Modal Class:
The class with the highest frequency in a grouped frequency distribution.
Weighted Mean:
An average used when different values have different levels of importance. Each value is multiplied by its assigned weight before calculating the average.

Probability

Probability:
A measure of the chance that an event will occur. Its value lies between 0 and 1.
Single Event:
An event containing exactly one sample point.
Complementary Events:
Two events where one describes the occurrence of an event and the other describes its non-occurrence.
Relative Frequency:
An estimate of probability based on observed results from repeated trials. With more trials, it often approaches theoretical probability.
Expected Frequency:
The number of times an event is expected to occur, based on its probability and the total number of trials.

3. DEFINITIONS

Raw Data:
Data that has not been arranged in a systematic order.
Grouped Data:
Data arranged into classes with the frequency of each class recorded.
Class Limits:
The smallest and largest stated values that define a class, called the lower and upper class limits.
Class Boundaries:
The values that define the continuous lower and upper edges of a class.
Class Interval:
The range of values covered by a class.
Class Mark:
The average of the lower and upper limits or boundaries of a class.
Frequency:
The number of occurrences of a value or the number of observations in a class.
Cumulative Frequency:
The sum of the frequency of a class and the frequencies of all preceding classes.
Histogram:
A graph of adjacent rectangles representing a frequency distribution, with rectangle areas proportional to class frequencies.
Frequency Density:
The frequency of a class divided by the width of its class interval.
Frequency Polygon:
A graph formed by plotting class marks against frequencies and joining the plotted points with straight line segments.
Arithmetic Mean:
The sum of all data values divided by the number of values.
Median:
The central value of data arranged in order.
Mode:
The value that occurs most frequently in a data set.
Unimodal:
A data set having one mode.
Bimodal:
A data set having two modes.
Trimodal:
A data set having three modes.
Modal Class:
The class having the highest frequency.
Weight:
A numerical value assigned to express the relative importance of a data value.
Weighted Mean:
The average calculated by multiplying each value by its weight, adding these products, and dividing by the sum of weights.
Probability:
A numerical measure of the likelihood of an event occurring.
Experiment:
A process or activity that produces an outcome.
Trial:
A single performance of a probability experiment.
Outcome:
A possible result of an experiment.
Sample Space:
The set of all possible outcomes of an experiment.
Event:
A set of one or more outcomes of an experiment.
Single / Simple Event:
An event containing exactly one sample point.
Impossible Event:
An event that cannot occur and has probability 0.
Sure Event:
An event that must occur and has probability 1.
Equally Likely Events:
Events that have the same chance of occurring.
Likely Event:
An event that has a greater chance of occurring than not occurring.
Unlikely Event:
An event that has a smaller chance of occurring than not occurring.
Mutually Exclusive Events:
Events that cannot occur together in the same trial.
Exhaustive Events:
A collection of events that together include all possible outcomes of an experiment.
Independent Events:
Events in which the occurrence of one does not affect the probability of the other.
Dependent Events:
Events in which the occurrence of one affects the probability of the other.
Complementary Event:
The event consisting of all outcomes in which the original event does not occur.
Relative Frequency:
The ratio of the number of times an event occurs to the total number of trials.
Expected Frequency:
The number of occurrences predicted for an event using its probability and the number of trials.

4. KEY POINTS

Frequency Distribution
• The sum of all frequencies must equal the total number of observations.
• Tally marks are useful for unarranged data.
• Class boundaries help remove gaps between consecutive classes.
• Class marks represent the midpoints of classes.
Graphs
• Histogram rectangles touch each other.
• For equal class widths, heights are proportional to frequencies.
• For unequal class widths, use frequency density for rectangle heights.
• A frequency polygon uses class marks and frequencies.
• Add zero-frequency classes at both ends to close a frequency polygon.
Arithmetic Mean
• Mean = Sum of Values / Number of Values.
• For frequency data, use Σfx / Σf.
• For grouped intervals, use class marks as the values.
Median
• Arrange ungrouped data before finding the median.
• For an odd number of observations, use the middle value.
• For an even number, average the two middle values.
• For grouped data, use cumulative frequency to locate the median class.
• In the grouped median formula, c is the cumulative frequency of the class BEFORE the median class.
Mode
• The mode is the most frequently occurring value.
• The modal class has the highest frequency.
• A data set may be unimodal, bimodal or trimodal.
• If all values occur equally often, there is no unique mode.
• For grouped mode, use class boundaries and the frequencies of the modal class and its neighbouring classes.
Weighted Mean
• Use weights when values are not equally important.
• Multiply each value by its corresponding weight.
• Divide the sum of weighted values by the sum of weights.
Probability
• Probability always lies between 0 and 1.
• Impossible event: probability 0.
• Certain event: probability 1.
• For equally likely outcomes, divide favourable outcomes by total outcomes.
• The probabilities of complementary events add up to 1.
Relative and Expected Frequency
• Relative frequency is also called experimental or empirical probability.
• Relative frequency is based on observed trials.
• With more trials, relative frequency often gets closer to theoretical probability.
• Expected frequency = Number of Trials × Probability of the Event.
