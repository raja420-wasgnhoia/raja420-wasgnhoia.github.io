FORMULAS & RULES

1. General Form of a Linear Equation
ax + b = c, where a ≠ 0 and a, b, c are constants.
2. Balance Rules
Same number added to both sides:
a = b ⟹ a + k = b + k

Same number subtracted from both sides:
a = b ⟹ a − k = b − k

Both sides multiplied by the same number:
a = b ⟹ ak = bk

Both sides divided by the same non-zero number:
a = b ⟹ a/k = b/k, where k ≠ 0.
3. Type 1: Subtraction
x − 8 = 20
x − 8 + 8 = 20 + 8
x = 28
4. Checking a Solution
For x − 8 = 20, put x = 28:
28 − 8 = 20
20 = 20 ✓
Therefore, x = 28 is the correct solution.
5. Type 2: Addition
x + 9 = 15
x + 9 − 9 = 15 − 9
x = 6
6. Type 3: Fractional Coefficient
(1/3)x = 4
3 × (1/3)x = 3 × 4
x = 12
7. Type 4: Multiplication
5x = 10
5x/5 = 10/5
x = 2
8. Type 5: Two-Step Equation
3x + 7 = 13
3x + 7 − 7 = 13 − 7
3x = 6
3x/3 = 6/3
x = 2
9. Equation Involving Fractions
x/2 − 6 = 8 − 2x/3
Add 2x/3 to both sides:
x/2 + 2x/3 − 6 = 8
x/2 + 2x/3 = 14
(3x + 4x)/6 = 14
7x/6 = 14
7x = 84
x = 12
10. Equation with Brackets in Denominator
(y + 4)/(2y − 3) = 2/5
Multiply both sides by 5(2y − 3):
5(y + 4) = 2(2y − 3)
5y + 20 = 4y − 6
5y − 4y = −6 − 20
y = −26
Restriction: 2y − 3 ≠ 0.
11. Equation Involving Decimals
6x + 5(3 − 1.4x) = 1.7
Expand:
6x + 15 − 7x = 1.7
−x + 15 = 1.7
−x = 1.7 − 15
−x = −13.3
x = 13.3
12. Application: Son's and Man's Ages
Let son's present age = x years.
Man's present age = 3x years.
After 10 years:
(x + 10) + (3x + 10) = 76
4x + 20 = 76
4x = 56
x = 14
Son's present age = 14 years.
Man's present age = 3 × 14 = 42 years.
Man's age when his son was born = 42 − 14 = 28 years.
13. Application: Sharing Money
Let Kaleem's amount = x.
Furqan's amount = x.
Amna's amount = Rs. 50.
Total = Rs. 250.
x + x + 50 = 250
2x + 50 = 250
2x = 200
x = Rs. 100
14. Word Problem: Think of a Number
A number multiplied by 4, then decreased by 6, gives 26.
Let the number be x.
4x − 6 = 26
4x = 32
x = 8
15. Consecutive Even Numbers
First even number = x
Second even number = x + 2
Third even number = x + 4
Their sum is 60:
x + (x + 2) + (x + 4) = 60
3x + 6 = 60
3x = 54
x = 18
The numbers are 18, 20, 22.
16. Constructing an Equation
A number increased by 4 equals 10:
y + 4 = 10

Seven added to five times a number equals 27:
5y + 7 = 27

A number increased by 20 equals 50:
x + 20 = 50

Twice a number decreased by 6 equals 14:
2x − 6 = 14

CONCEPTS

1. Algebraic Sentence
A mathematical statement containing an algebraic expression and a relation sign such as =, ≠, <, >, ≤ or ≥.
2. Equation and Inequality
An equation contains the equal sign (=), for example x + 8 = 12.
An inequality compares quantities using signs such as <, >, ≤ or ≥, for example 5 < 8.
3. Balance Scale Model
An equation is like a balanced scale. Both sides must remain equal. Performing the same valid operation on both sides preserves the balance.
4. True, False and Open Sentences
A mathematical sentence is true if the statement holds, false if it does not, and open if its truth depends on an unknown variable.
5. Solving a Linear Equation
Use inverse operations to isolate the variable. Addition is undone by subtraction, multiplication by division, and vice versa.
6. Equations with Fractions and Decimals
Simplify brackets, combine like terms and use valid operations on both sides to find the unknown value.
7. Applications of Linear Equations
Daily-life problems involving ages, money, numbers and quantities can be translated into equations and solved algebraically.
8. Bar Model and Algebraic Method
The bar model represents unknown quantities with boxes. The algebraic method replaces each unknown box with a variable such as x.

DEFINITIONS

1. Equation
An open sentence that contains an equal-to sign (=) is called an equation.
2. Linear Equation in One Variable
An equation of the form ax + b = c, where a ≠ 0 and a, b and c are constants, is called a linear equation in one variable.
3. Solution of a Linear Equation
The value of the variable that makes an equation true is called its solution.
4. Open Sentence
A mathematical sentence containing a variable whose truth cannot be determined until the variable's value is known is called an open sentence.
5. Inequality
A mathematical statement that compares two quantities using signs such as <, >, ≤ or ≥ is called an inequality.
6. Constant
A fixed numerical value that does not change is called a constant.
7. Variable
A symbol, usually a letter, that represents an unknown or changing value is called a variable.

KEY POINTS

1. The equal sign (=) shows that both sides of an equation have the same value.
2. In ax + b = c, the coefficient a must not be zero.
3. In a linear equation, the highest power of the variable is 1.
4. Always perform the same operation on both sides of an equation to preserve equality.
5. Never divide either side of an equation by zero.
6. Check a solution by substituting the value of the variable into the original equation.
7. Simplify brackets and combine like terms before isolating the variable.
8. In word problems, define the unknown first, form an equation, solve it and interpret the answer.
9. Consecutive even numbers differ by 2. They can be represented by x, x + 2 and x + 4.
10. For the equation (y + 4)/(2y − 3) = 2/5, the denominator cannot be zero.
11. For x/2 − 6 = 8 − 2x/3, the solution is x = 12.
12. For 6x + 5(3 − 1.4x) = 1.7, the solution is x = 13.3.
